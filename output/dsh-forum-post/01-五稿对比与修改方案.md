# DSH 插件清单贴：五稿对比与修改方案

> 对比对象：DeepSeek / kimi / Perplexity / 豆包 / 元宝 五份改写稿（原文见本目录 `原稿/` 同名文件）
> 目标平台：DSH 社区论坛（帖文体）
> 核对基准：2026-11-14 实测 —— 线上精选目录 10936 条、npm registry 最新版本、本机 DSH 0.1.0-rc.8 的真实安装清单

## 一、结论先说

**kimi 稿对社区最友好**——它是五稿里唯一读起来像"真人真的用过"的。改 4 处就能发。

其余四稿各有硬伤：

| 稿子 | 一句话诊断 |
|---|---|
| **kimi** ⭐ | 最佳底稿。标题最像经验分享、口吻最自然、结尾互动最社区化。但正文里留了"改稿说明"，还有一处脏话、一个夸张排版、三处事实错误。删改完即可发。 |
| **豆包** | 骨架最干净、编号最规整。但**两个可执行代码块里带 `mailto:` 前缀**（照抄必失败），加上满篇营销号腔（"必装合集""白嫖神器""阉割""少走 90% 弯路"）。 |
| **Perplexity** | 最安全、最专业，**但最没用**。它把最有价值的那条可执行命令整段删了，全篇"以当前版本为准"式对冲，还留着 `[[github](url)]` 的引用残留。读者读完拿不到任何能直接跑的东西。 |
| **元宝** | 中规中矩。`mailto:` bug + emoji 分节 + "梁文锋（梁圣）"这种别扭写法，属于"改过但没改干净"。 |
| **DeepSeek** | **不能直接发**。没有标题，正文里还留着"原稿里的 `mailto:` 前缀已去掉"这种改稿备注——读者一眼看出是 AI 加工过的稿。 |

## 二、逐稿问题（附原文）

### kimi 稿 · 最佳底稿，改 4 处

| 问题 | 原文 |
|---|---|
| 改稿说明混进正文，读者第一屏就出戏 | `改好了，整体做了这几件事：` / 结尾整张 `改动说明（挑重点说）` 表格 |
| 脏话过线，论坛评论区容易挨喷 | `内心一万只草泥马奔过` |
| 排版太用力，像营销号 | `还!不!能!直!接!用!` |
| 标题数字与正文对不上 | 标题 `从 30 个删到只剩这 9 个`，正文却写 `折腾了一周、删了二十多个插件` |

### 豆包稿 · 骨架干净，命令有毒

- **致命**：两处可执行命令里混进了 `mailto:`，照抄必然失败——
  `target填写npm包[dsh-free-model@3.1.0](mailto:dsh-free-model@3.1.0)`
  `...plugin --profile desktop add [dsh-free-model@3.1.0](mailto:dsh-free-model@3.1.0)`
- 营销腔过重：`必装插件合集`、`白嫖神器`、`新版已经阉割了免费接口`、`账单刺客`、`少走90%弯路`
- 结论没落地：`最后总结` 只讲理念，没给"新手按什么顺序装"

### Perplexity 稿 · 最安全，也最没用

- 唯一识别出「装旧版」这条建议有问题，但直接**删掉整条命令**，读者拿不到替代方案
- 全篇对冲：`以当前版本的实际界面为准`、`都可能会变化`、`不代表每个人都会遇到` —— 安全，但读者读完什么也做不了
- 引用残留：`[[github](https://github.com/...)]` 是 Perplexity 自己的引用语法，搬进论坛会露出马脚
- 唯一被它说中且**其余四稿全错**的一点：`@` 自动联想项目文件——见下方事实核对第 4 条

### 元宝 稿 · 改过但没改干净

- `mailto:` bug 同样在代码块里（`add mailto:dsh-free-model@3.1.0`）
- `按照梁文锋（梁圣）的说法` —— 括号里那三个字是多余的
- emoji 做小节标题（`#### 📎 dsh-file-attachment`），一屏五六个，论坛观感偏轻浮
- 结尾又问"要不要我帮你再精简一版"——这是跟 AI 对话的尾巴，读者看到会觉得作者在摆拍

### DeepSeek 稿 · 发布事故级

- **全文没有标题**，论坛发帖没标题等于没发
- 正文里的改稿备注：
  `> 注：下面命令里的 npm 包名以代码块为准，原稿里的 mailto: 前缀已去掉。`
  这一行直接告诉读者"这稿子是 AI 改的"
- 裸链接不转 Markdown 链接（`https://github.com/omdsh-dev/DSH-better-sidebar/` 裸露在正文）
- 人名错：`梁圣` / `按照梁圣的说法` —— 应为**梁文锋**；用错名字比不称呼更尴尬
- 章节编号从「二」跳到「三、避坑指南」，中间 5. 钱包保镖 之后少了「三」

## 三、事实核对（这是五稿共同的雷区）

以下全部为 2026-11-14 实测结果，**原样发出去会被评论区当场打脸**：

### ① 「最新版阉割了免费接口，要装 3.1.0 旧版」—— 说反了

- npm `dsh-free-model` 当前 **latest = 3.1.0**，发布于 2026-11-11。**3.1.0 就是最新版**，不是旧版。
- 这个包的真实身份：`dsh-free-model`（作者 YpipaQ）是 `Ebony-Vinyl/dsh-our-free-model` 的**精简 fork**，README 自己写明——

  > 只保留「把外部账号接进来」这一条车道：**十五个账号渠道 + 数据看板 + 运行日志 + 本地网关**。上游的匿名免费车道、EAC 协付车道、聚合渠道、省 Token、路由与发布/更新通道**全部移除**。

  也就是说，**免费车道是作者主动砍的 fork 设计，不是"官方藏起来"**。而且上游 `dsh-our-free-model` 是 GitHub 分发、根本没有 npm 包，五稿那条 `dsh-free-model@3.1.0` 的命令压根不是上游。

  > 社区影响：把一个作者的**刻意精简设计**说成"被阉割、要回退旧版绕过"，等于当面教人钻空子。插件作者看到会很难受，论坛也会判定你不懂装。

  **改法**：如实写两个包的分工，给两条命令让读者自己选，不做"邪道"叙事。

### ② 「一共 13 个免费模型」—— 数字对不上

- 本机 `~/.dsh/our-free-model/catalog.json`（2026-11-14 更新）当前是 **11 条**免费模型条目：`mimo-v2.6-flash-free`、`deepseek-v4.1-flash-free`、`glm-5.3-flash-free`、`longcat-2.5-free`、`iceman-free`、`inkling-2-small-free`、`beam-free`、`flint-40b-free`、`nemotron-3.5-super-vl-free`、`nemotron-3.5-lightning-free`、`minimax-m3.1-flash-free`。
- 渠道（sealIds）12 条，另有一张 14 行的第三方通道表。**13 这个数字对不上任何一个口径**，而且这列表会随上游变。
- **改法**：写"当前目录里是 11 条免费模型入口，会随上游变动"，或干脆不写死数字。

### ③ 「官方默认没把图形化商店放在显眼位置」—— 已经不准了

- 官方现在有 `@deepseek-ai/dsh-experimental-plugin-market-bundle`（本机装的是 `0.2.2-rc.3`，npm latest `0.2.1-alpha.4`），是官方自己的插件市场 bundle。
- 五稿统一口径是"官方没有商店、只有 GitHub 翻仓库"，这在官方粉丝眼里是**过时且有失偏颇**的描述。
- **改法**：官方 experimental bundle 与社区市场并列介绍，一句"官方在推进、市场更全"，不贬低也不吹。

### ④ 「输入 `@` 自动联想项目里所有文件」—— 五稿全错，只有 Perplexity 怀疑对了

- `@wszhoho/dsh-file-attachment@0.7.4` 的官方描述是：**拖拽 / `Ctrl+V` 粘贴 / 📎 按钮上传**，文件统一落盘到 `.dsh-file-attachment` 并以 **`@绝对路径` 引用**发送；非多模态模型下图片自动调用可配置 VLM 生成中文描述。**没有任何"@ 联想项目文件树"的功能**。
- `@绝对路径` 引用 和 `@` 联想弹窗是两回事——五稿把 DSH 主输入框自带的能力，记到了这个插件头上。
- **改法**：改成"拖拽/粘贴/上传，落盘后用 `@绝对路径` 引用"，并注明"输入框里想直接补全路径，那是 DSH 本身的能力"。

### ⑤ `--profile desktop` 与 `--profile web` 混用

- 官方精选目录里 **每一条** install 命令都是 `dsh plugin --profile web add ...`；市场自己的 README 也是 `--profile web`。
- 但本机 `~/.dsh/profiles/` 下确实同时有 `web` 和 `desktop` 两个 profile——**桌面客户端用 `desktop`，纯网页版用 `web`**。
- 五稿一律写 `desktop`，网页版用户照抄会装错 profile（或者装到没在跑的那个环境里）。
- **改法**：给命令时明确标注"网页版用 `web`，桌面客户端把 `web` 换成 `desktop`"，并补一句市场内点安装会自动对上。

### ⑥ 插件真名与作者对不上

五稿里的"插件名"和线上真实条目差得有点多，读者按名字搜不到：

| 稿里写的 | 线上真实条目 | 安装命令 |
|---|---|---|
| Brilliant Context | **`billion-context`**（7263 star） | `dsh plugin --profile web add billion-context` |
| Rewind（后悔药） | **`dsh-rewind`**（npm `dsh-rewind-plugin`，266 star） | `dsh plugin --profile web add dsh-rewind-plugin` |
| Mod Search | **`modsearch`**（npm `@liustack/modsearch`，981 star） | `dsh plugin --profile web add @liustack/modsearch` |
| Vision Router | **`dsh-vision-router`**（172 star） | `dsh plugin --profile web add dsh-vision-router` |
| DSH Browser | **`dsh-builtin-browser`** | `dsh plugin --profile web add dsh-builtin-browser` |
| DeepSeek-Balance-Whale-Widget | **`DeepSeek-Balance-Whale-Widget`**（npm `dsh-whale-widget`，7201 star） | `dsh plugin --profile web add dsh-whale-widget` |
| dsh-file-attachment | **`dsh-file-attachment`**（npm `@wszhoho/dsh-file-attachment`） | `dsh plugin --profile web add @wszhoho/dsh-file-attachment` |
| DSH Pocket | **`dsh-pocket`** | `dsh plugin --profile web add dsh-pocket` |
| DSH IM | **`dsh-im`**（npm `@xmanrui/dsh-im`，3574 star，支持 9 种渠道含 QQ） | `dsh plugin --profile web add @xmanrui/dsh-im` |

> ⚠️ **`dsh-file-attachment` 在 npm 上是 404**——它只有 scoped 包 `@wszhoho/dsh-file-attachment`，五稿没写包名，读者照抄 `--profile desktop add dsh-file-attachment` 会失败。

### ⑦ 「6 元代金券」—— 无法核实

注册送额度和活动政策随时变，且我这边没有官方页面可查证。
**改法**：写成"新注册一般会有体验额度，具体金额和有效期以你注册时看到的活动页为准"。

### ⑧ 值得单独提的隐私点（五稿全没提，但社区会很在意）

`dsh-vision-router@3.2.1` 的 README 自带 CAUTION 声明：

> **Data leaves your machine by default.** 默认启用匿名 OVHcloud 视觉兜底，"免费""免 key"**不等于离线**。机密/合规材料不要走云端链路。

同一段 README 里还写明：DeepGuard 徽标指向的是 2.0.1 的历史审计，**不代表当前版本的认证**。

**改法**：在"识图"那节加一句"默认会把图片发到云端视觉模型，涉密材料记得切本地或关掉兜底"。这种提醒是社区里最容易收获好感的地方。

## 四、改稿的 12 条规则

按优先级排，前 6 条不做到会出事：

1. **删掉所有改稿痕迹** —— "改好了""改动说明""要不要我再给你精简一版"，一律不留。
2. **加标题** —— 论坛发帖没标题等于没发。用真实数字（你本机社区插件 **12 个**），别用对不上的数字。
3. **命令逐条校验** —— 包名、大小写、`@scope`、`--profile` 全部照抄官方精选目录的写法；禁止 `mailto:` 前缀。
4. **事实对齐到 2026-11-14** —— 3.1.0 是最新版、11 条免费模型、file-attachment 没有 `@` 联想、官方已有 experimental market bundle。
5. **声明利益相关** —— 你是 DSH Market 的维护者，第一句就写明"这个市场是我做的"。**主动说破比被看出来好一百倍**；不声明才是真的减分。
6. **别教人钻空子** —— 删掉"邪道""阉割""装旧版绕过"，改成如实说明两个包的分工。
7. **别嘲讽友商** —— 删掉 `OpenAI 还在搞自嗨 GPTs`、`Claude 依然搞"封"狂政策`。在 DSH 社区里对比嘲讽是最容易招杠的操作，而且和你的主题无关。
8. **黑话降级** —— 白嫖/薅羊毛/账单刺客/毒奶 → 额度/用量/预算/踩坑。
9. **每个插件写清"解决什么问题"** —— 社区要的是"我该装哪个"，不是"这个插件多神"。
10. **安全提醒保留并加强** —— 社交通道用小号、视觉插件默认上云、装插件前看清权限。
11. **给新手一条明确的安装顺序** —— Perplexity 稿的第四节（六步）值得抄过来，那是全篇最有用的部分。
12. **结尾留互动口** —— kimi 稿那句"欢迎在评论区推荐，我再补楼完善"保留，再补一句反馈入口。
