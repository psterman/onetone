## 一、插件怎么装？

初学者最头疼的是：官方默认没把图形化商店放在最显眼的位置。如果没装管理工具，你得去 GitHub 上翻仓库。所以第一步，建议先装“工具的工具”。

当然，还是建议各位先安装 DSH 桌面客户端：去官网下载桌面安装包（支持 Windows 与 macOS）。**强烈建议不要装在 C 盘系统盘！**

建议先用手机登录 DeepSeek Harness。梁总给注册用户送了 6 元代金券，够你先免费用 DeepSeek 官方大模型办点事。

点“添加插件”，输入：

```text
https://github.com/dsh-market/dsh-market
```

中途可能会中断一次，弹窗选允许安装即可；后面可以用插件跳过这个烦人的步骤。

### DSH Market（插件超级市场）

**做什么的：** 广大网友用爱发电的插件综合社区，能按点赞数、安装数和日期筛选热门插件，方便你搜索与安装。

**安装技巧：** 如果你觉得安装麻烦，可以在选项页面里填写你的大模型 Token，财大气粗一点，一句话让 DSH 自己装。

**报错怎么办？** DSH 处于高速迭代期，有时候界面点击安装会因为网络或依赖环境报错。最稳妥的办法是点进该插件的“源码仓库（GitHub）”，直接复制作者给出的原生安装命令行，让 AI 在对话框执行，或者在终端敲一遍，成功率更高。  
或者你把报错信息发给 DSH，让它帮你排查问题。

## 二、必装神级插件：只留真正干活的

### 0. 白嫖之王：DSH-Our Free Model

**说明：** 这个基本是人均必装，可以帮你薅各家大模型的羊毛。确保你在完全不知道什么是 Token、API、大模型之前，先把 DSH 用起来。

**使用方法：** 不要直接搜索 `dsh-our-free-model` 安装，因为插件最新版本已经隐藏了核心羊毛，建议安装老版本。但安装方法咱们就要开始走“邪道”了。

> 注：下面命令里的 npm 包名以代码块为准，原稿里的 `mailto:` 前缀已去掉。

**方法一：** 登录 DSH，用梁圣送你的免费额度，给 DSH 发这句话：

```text
用 plugin_manager 的 install_bundle 安装插件，target 传 npm 包 dsh-free-model@3.1.0，装到 profile desktop。装完确认 node_modules/dsh-free-model/package.json 的 version 是 3.1.0。
```

**方法二：** 右键开始菜单，打开命令行窗口，输入下面这句“咒语”。注意把“你的 DSH 安装地址”改成你的 DSH 实际安装地址。比如我安装在 `D:\DSH`，就是下面这句，别漏掉引号：

```bat
& "你的DSH安装地址\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-free-model@3.1.0
```

例如：

```bat
& "D:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-free-model@3.1.0
```

安装后记得彻底退出 DSH，再重新启动。

不过现在还不能直接用。从“设置 → Our Free Model”页面进来，一一登录配置和你账号相关的大模型。一共 13 个免费大模型，按需登录授权。  
然后你就能在对话框的模型列表里找到新加入的羊毛大模型了。

### 1. 工作台与界面骨架类

**DSH-better-sidebar（侧边栏与多功能看板）**  
https://github.com/omdsh-dev/DSH-better-sidebar/

**痛点：** 原生 DSH 只有中间一个对话框，AI 生成的文件打不开，也看不到本地目录。

**使用方法：** 装上后直接补齐右侧管理器。点击 `.md` 文档或 `.html` 网页能实时分栏预览，不用来回切窗口。  
同时它整合了任务看板、浏览器、归档管理、多标签对话，还能在底部加抽屉式持久终端，相当于给 DSH 的右翼加了一个综合管理工作台。

### 2. 上下文与文件管理类

**dsh-file-attachment**  
https://github.com/wszhoho/dsh-file-attachment

**痛点：** 要让 DSH 读某个本地配置文件，还得手动复制一大段路径。

**使用方法：** 在对话框输入 `@`，系统会自动弹窗联想当前项目里的所有文件和子目录，点选即可精准喂给 DSH；也支持拖入、`Ctrl+V` 粘贴，PC 和移动端浏览器都能用。

**Brilliant Context（长会话交接与防胀减负）**

**痛点：** 多轮对话后，历史记录越来越长，不仅 Token 越跑越贵，模型还容易忘掉前面的关键约束。

**使用：** 它在后台维护一份“会话交接文档”，自动把你和 DSH 的琐碎过程分段压缩、提炼成核心摘要，大幅削减每次发给模型的历史负担，既防爆上下文，又帮你省下大笔开销。

### 3. 视觉与网络自动化

**Vision Router**

**痛点：** DeepSeek 很多纯文本模型遇到报错截图或设计图时，会直接提示“模型不支持图像”。

**使用：** 装上后记得重启，模型列表里会多出对应的视觉路由选项。当对话里包含图片时，它会自动调度你配置的视觉工具通道或第三方视觉 API 做 OCR 与排版解析。遇到问题把报错截图发过去，DSH 从此秒懂。

**Mod Search 与 DSH Browser（真实联网与拟人操控）**

**痛点：** 很多网站有复杂的反爬机制，或者需要翻页、交互才能拿到最新数据。

**使用：** 如果说 Vision Router 是眼睛，那 Mod Search 和 DSH Browser 就是手脚。Mod Search 能聚合全网搜索引擎，把搜索结果整理成带引用的结构化卡片；DSH Browser 则能调起真实的独立浏览器实例，模拟人类滚动、点击、截屏并读取网页，悬浮窗里还能全程看它操作，必要时你可以随时接管。

**实操建议：** 可以专门建一个独立的 Chrome Profile 供它跑，综合能力最强，登录账号相对齐全，安全又干净。

### 4. 钱包保镖类（计费监控与防跑飞）

**DeepSeek-Balance-Whale-Widget（钱包管家）**  
https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget

**痛点：** 不知道任务跑了多少钱，容易遭遇“账单刺客”。

**使用：** 帮你在 DSH 右下角加一个钱包提醒挂件：小鲸鱼气泡图 + DeepSeek API 余额 + 今日已用 + 每轮对话消耗。挂件人物、余额提醒、气泡内容都能完全自定义。

**建议：** 配一个每日预算熔断插件，支持自定义单日消耗上限（比如 50 元或 100 元）。消耗到 80% 弹窗预警，到 100% 自动暂停对话，彻底防后台死循环把余额刷光。

### 5. 任务管理与防后悔类

**Rewind（后悔药）**

**痛点：** 平时改方案，改了五轮后发现还不如第三轮写得好。

**使用：** 用它可以精准把对话历史回退到前面某一步，重新提要求，不用硬着头皮从头再来。

**DSH pocket（人在外地，遥控本地）**

**痛点：** 如果你经常需要通过手机访问 DSH，但用 UU 远程这类工具还要登录，反复放大确认，很麻烦。

**使用：** pocket 可以实现手机和电脑同步操作访问，在家（同一局域网）在外都能操作 DSH。不过这个软件现在有个 bug：和部分插件不兼容，手机竖屏容易显示白屏，可以横屏操作，或者先排查插件再使用。

**DSH IM（你的 DSH 小助手）**

**痛点：** 微信、QQ 这些常用机器人很笨，也不支持接入大模型，每次问问题都要打开特定程序，很烦。

**使用：** 通过 IM 扫码连接后，DSH 就能成为你常驻的小助手。你只要微信/飞书/QQ 在线，就可以和 DSH 专属小助手聊天。  
比如在微信里敲一句：“查一下我电脑昨天的汇报草稿。”常驻在家里电脑上的 DSH 会自动搜集整理，并把摘要回传给你。

## 三、避坑指南

### 1. 同质化严重，千万别“集邮”

插件太丰富，民间放羊式管理，光是查余额、做侧边栏的插件就有几十上百个。  
**建议：同类插件选 Star 最高、维护活跃的一个即可。**

### 2. 版本破坏性更新：红屏报错怎么救？

官方底层一升级，第三方插件红掉就是家常便饭。  
更新主程序前务必备份工作区；遇到插件报错，优先去作者的 GitHub 看看有没有针对新版发补丁，或者先在设置里临时卸载，等待修复。

### 3. 插件底层的“卸载干净”玄机

DSH 底层基于北大与 DeepSeek 联合研发的 Cordis 系统。它在数学层面上追求“时间可组合性”（插件卸载后残留配置能彻底抹除）和“空间可组合性”（插件之间能动态声明依赖）。  
但第三方小作者的脚本如果不规范，仍可能留下脏配置。如果删了插件还报错，让 DSH 清理相关配置文件，可能就能恢复。

### 4. 社交通道集成必须用小号

注意：用插件把 DSH 挂接到 QQ 或其他社交群聊里，必须注册独立小号，不要使用主力私人号，防止高频自动化响应触发社交平台风控封号机制。
