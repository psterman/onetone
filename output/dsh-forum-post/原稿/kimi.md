# 折腾 DSH 三天后，我把插件从 30 个删到只剩这 9 个（附安装手册和避坑指南）

很多人折腾 DeepSeek Harness（下文简称 DSH），第一天就大概率掉进两种极端：

- 打开官方原生界面，面对空荡荡一个聊天框，内心一万只草泥马奔过——"就这？还要我自掏 token？"
- 热血冲进社区插件列表，看到什么都想装，一口气怼了几十个上去。结果呢？界面挤爆、插件互相打架、后台隔三差五蹦红字报错。

我就是从第二种状态爬出来的。折腾了一周、删了二十多个插件之后，今天把我的"幸存者清单"分享出来：**不讲代码，只讲实用**，附安装技巧和踩过的雷。

## 一、插件怎么装？

对新手来说，最反直觉的一点是：官方默认没把图形化商店放在显眼位置。没装管理工具之前，你只能去 GitHub 手动翻仓库。

所以第一步，建议先装一个"工具的工具"。

**前置工作，建议照做：**

1. 先去官网下载 DSH 桌面客户端（支持 Windows 和 macOS）。**强烈建议不要装在 C 盘**，血泪教训不解释。
2. 用手机登录 DeepSeek Harness，梁圣给注册用户送了 6 元代金券，相当于先白嫖官方大模型把环境跑起来。
3. 点"添加插件"按钮，输入：

```
https://github.com/dsh-market/dsh-market
```

中途可能会提示一次中断，快速点"允许安装"即可。后面我们会用插件来跳过这种烦人的确认步骤。

**DSH Market（插件超级市场）——干啥的？**

就是广大网友用爱发电的插件综合社区。支持按点赞数、安装数、日期排序，热门插件一目了然，搜索安装一条龙。

**安装技巧：**

- 嫌麻烦的话，可以"财大气粗"地在选项页面填上自己的大模型 token，一句话让 DSH 自己完成安装。
- **报错了怎么办？** DSH 现在处于高速迭代期，界面点安装偶尔会因为网络或依赖环境翻车。最稳妥的办法是点进该插件的"源码仓库（GitHub）"，直接复制作者给出的原生安装命令行，让 AI 在对话框执行，或者自己在终端敲一遍，成功率明显更高。
- 实在不行，把报错信息原样发给 DSH，让它帮你排查。

## 二、必装神级插件：只留真正干活的

### 0. 白嫖之王：DSH-Our Free Model

人均必装。帮你薅各家大模型的羊毛，确保你在完全不懂什么是 token、API、大模型之前，就能把 DSH 先用起来。

**注意：** 不要直接搜索 `dsh-our-free-model` 装最新版——最新版本已经隐藏了核心羊毛，建议装 **3.1.0 老版本**。安装方法必须"邪道"：

**方法一（推荐）：** 登录 DSH，用梁圣送的免费额度，直接给它发这句话：

> 用 plugin_manager 的 install_bundle 安装插件，target 传 npm 包 `dsh-free-model@3.1.0`，装到 profile desktop。装完确认 node_modules/dsh-free-model/package.json 的 version 是 3.1.0。

**方法二（命令行）：** 右键开始菜单，打开命令行窗口，输入：

```
& "你的DSH安装地址\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-free-model@3.1.0
```

⚠️ 把 `你的DSH安装地址` 替换成实际路径，比如我装在 `D:\DSH`，引号一个都不能少。

装完后**彻底退出再重启**——还!不!能!直!接!用!

从「设置 → OurFreeModel」页面进来，把和你账号相关的大模型**逐一登录授权**，一共 13 个免费模型，按需配置。然后你就能在对话框的模型列表里看到这些新加入的羊毛了。

### 1. 工作台与界面骨架类

**DSH-better-sidebar**（[项目地址](https://github.com/omdsh-dev/DSH-better-sidebar/)）

- **痛点：** 原生 DSH 只有中间一个对话框，AI 生成的文件打不开，也看不到本地目录。
- **用法：** 装上即补齐右侧管理器。点击 `.md` 文档或 `.html` 网页能实时分栏预览，不用来回切窗口。还整合了任务看板、浏览器、归档管理、多标签对话，底部可以加一个抽屉式持久终端——等于给你的 DSH 右翼塞了一个综合管理工作台。

### 2. 上下文与文件管理类

**[dsh-file-attachment](https://github.com/wszhoho/dsh-file-attachment)**

- **痛点：** 想让 DSH 读个本地配置文件，还得手动复制一大段路径，反人类。
- **用法：** 在对话框输入 `@`，自动联想弹出当前项目的所有文件和子目录，点选即精准投喂；也支持拖拽和 `Ctrl+V` 粘贴，PC 和移动端浏览器都能用。

**Brilliant Context（长会话交接与防胀减负）**

- **痛点：** 多轮对话后历史记录越滚越长，Token 越烧越贵，模型还容易忘掉前面的关键约束。
- **用法：** 它在后台维护一份"会话交接文档"，自动把琐碎过程分段压缩、提炼成核心摘要，大幅削减每次发给模型的历史负担。防爆上下文，还能帮你省一大笔。

### 3. 视觉与网络自动化

**Vision Router**

- **痛点：** DeepSeek 很多纯文本模型遇到报错截图或设计稿，直接甩你一句"模型不支持图像"。
- **用法：** 装上后记得重启，模型列表会多出视觉路由选项。对话里带图时，它会自动调度你配置的视觉通道或第三方视觉 API 做 OCR 和排版解析。把报错截图丢过去，DSH 从此秒懂。

**Mod Search 与 DSH Browser（真实联网与拟人操控）**

- **痛点：** 很多网站反爬严格，或者需要翻页、交互才能拿到最新数据。
- **用法：** 如果说 Vision Router 是眼睛，这两位就是手脚。Mod Search 聚合全网搜索引擎，把结果整理成带引用的结构化卡片；DSH Browser 则调起真实独立浏览器实例，模拟人类滚动、点击、截屏、读网页，悬浮窗里能全程围观它操作，关键时刻随时接管。
- **实操建议：** 单独建一个独立 Chrome Profile 给它跑，能力最全，相关登录账号比较齐全，相对安全又干净。

### 4. 钱包保镖类

**[DeepSeek-Balance-Whale-Widget（钱包管家）](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)**

- **痛点：** 任务跑完才知道花了多少钱，容易遭遇"账单刺客"。
- **用法：** 在 DSH 右下角挂一个钱包提醒挂件：小鲸鱼气泡 + DeepSeek API 余额 + 今日已用 + 每轮对话消耗，人物、余额提醒、泡泡内容全部可以自定义。

**另建议装一个每日预算熔断插件：** 自定义单日消耗上限（比如 50 或 100 元），用到 80% 弹窗预警，到 100% 自动暂停对话。防的就是后台死循环把你的余额刷光。

### 5. 任务管理与防后悔类

**Rewind（后悔药）**

- **痛点：** 改方案改了五轮，发现还不如第三轮写得好，心态崩了。
- **用法：** 一键把对话历史精准回退到之前的任意一步，重新提需求，不用硬着头皮往下圆。

**DSH Pocket（人在外地，遥控家里电脑）**

- **痛点：** 想用手机访问 DSH，用 UU 远程这类方案还要登录、反复放大确认，体验稀烂。
- **用法：** Pocket 实现手机和电脑同步操作，同一个网在家在外都能操控 DSH。
- **已知 BUG：** 和部分插件不兼容，手机竖屏容易白屏。可以横屏操作，或者排查插件后再用。

**DSH IM（你的 DSH 小助手）**

- **痛点：** 微信、QQ 自带的机器人很笨，又不支持接大模型，每次问问题还要专门打开某个程序，烦。
- **用法：** 通过 IM 扫码连接后，DSH 就成了你常驻的小助手。只要微信/飞书/QQ 在线，就能跟它聊天。比如你在微信里敲一句"查一下我电脑昨天的汇报草稿"，常驻在家用电脑上的 DSH 会自动搜集整理，把摘要回传给你。

## 三、避坑指南：这 5 个坑，我替你踩过了

**1. 同质化严重，千万别"集邮"**

插件太丰富，管理又是民间放羊式。光是查余额的、做侧边栏的插件就有几十上百个。建议同类插件只选 **Star 最高、维护最活跃**的一个，装完就走。

**2. 版本破坏性更新：红屏报错怎么救？**

官方底层一升级，第三方插件红掉是家常便饭。更新主程序前**务必备份工作区**；遇到插件报错，优先去作者 GitHub 看有没有针对新版的补丁，或者先在设置里临时卸载等修复。

**3. 插件底层"卸载干净"的玄机**

DSH 底层基于北大与 DeepSeek 联合研发的 Cordis 系统，在数学层面上追求"时间可组合性"（插件卸载后残留配置彻底抹除）和"空间可组合性"（插件间动态声明依赖）。但第三方小作者的脚本如果不规范，还是可能留下脏配置。删了插件还报错的话，让 DSH 清理一下相关配置文件，基本就能恢复。

**4. 社交通道集成必须用小号**

用插件把 DSH 挂到 QQ 或其他社交群聊时，**务必注册独立小号**，别用主力私人号。高频自动化响应很容易触发社交平台风控，封号没商量。

**5. 别把 DSH 当成"全自动印钞机"**

再神的插件也只是工具，复杂任务记得盯着点。钱包挂件 + 熔断插件双保险，是底线配置。
