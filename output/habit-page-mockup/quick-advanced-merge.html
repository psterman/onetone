变更对照

改前：三个平级模式
  • 小白 / 快速 / 程序员 三 tab 并列
  • 程序员 = 独立整页参数表
  • 与快速规则清单高度重叠
  • 无 JSON 导出入口
  • 误点率高，边界模糊
改后：快速设置 + 进阶折叠
  • 仅小白 / 快速两 tab
  • 规则 peek 增加来源标签 + 技术行
  • 「完整参数」默认折叠，熟练用户按需展开
  • 底部 JSON 复制 / 下载（只读）
  • 已存 programmer 偏好自动迁到 quick
