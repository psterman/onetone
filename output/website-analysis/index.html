一、核心发现摘要

🔴 最关键：部署版本与本地源码不同步

🟡 关键差距

可迁移的关键经验

1. Hero 文案极短

"我帮你" 3 个字 + 一句 60 字以内的价值主张。用户 3 秒就能读懂。

2. 首屏放真产品

不是静态截图，而是完整 App 外壳 + 工具调度时间线 + 产物下载。降低理解成本。

3. 价值量化

"从查资料到给结论，15 分钟交付报告" —— 用具体时间数字替代"高效"。

4. 双墙背书

生态墙讲"能连什么"，客户墙讲"谁在用"。两排 marquee 不停滚动强化信任。

5. 定价前置

首页就有 4 档方案，用划线价和"限时免费"锚定价值。

6. 全平台下载

列出 Mac / Windows / iOS / Android / 鸿蒙，并标注"当前设备"，减少用户犹豫。

四、OneTone 线上版 vs 本地版对比

线上 www.onetone.app：浅色 + 3D 麦克风 + 旋转文案

WorkBuddy：浅色 + 大 logo + 机器人吉祥物

线上 OneTone 在视觉风格上其实与 WorkBuddy 更接近（浅色、大插画、短文案），说明之前已有向"轻量官网"靠拢的尝试。但本地源码又切回了深色 HUD 故事线，造成用户-facing 品牌不统一。

七、可直接落地的改进建议

1. Hero 重构：从"口号"到"一句话价值 + 数字"

当前

"想什么，说一声"
按一下侧键就能开麦。Cursor、Claude、Trae……在哪写就在哪说，不用先找麦克风按钮。

建议

"侧键 = 麦克风"
3 分钟装好，按一下就在当前 App 里说话输入。支持 Windows 10/11。

2. 把"真产品演示"搬到首屏

参考 WorkBuddy 的"产品演示壳"，在 OneTone hero 下方放一个左右分栏：

  • 左侧：模拟用户 prompt，如"给 Cursor 写一段 React 按钮组件"
  • 中间：按下鼠标侧键 → 麦克风激活 → 声波动画
  • 右侧：Cursor 编辑器里文字逐字落入光标处
  • 底部：产物/状态栏 "已输入 87 字 · 耗时 8 秒"

3. 增加量化指标区

3 分钟完成安装到开麦
1 个键触发任意语音输入
11+Agent / IDE 兼容
100% 本地语音处理不上传

4. 社会证明升级

把现在的"品牌兼容墙"拆成两层：

  • 兼容生态：Cursor / Claude / ChatGPT / Trae / WorkBuddy…（保留现有）
  • 谁在用：社区截图、V2EX/即刻/微博真实反馈、GitHub stars 数、下载量（若有）

5. 导航与 CTA 优化

  • 主导航增加 文档（指向 FAQ 或未来 docs 站点）
  • Header 的"下载"按钮在首页保持 sticky，scroll 时缩小为 mini CTA
  • 每个 story 章节末尾加章节级 CTA："去绑定按键" / "看语音上手" / "试用 SoftPad"

6. 定价/方案区（若准备商业化）

即使目前免费，也可学习 WorkBuddy 放一档：

  • 免费版：所有核心功能，本地运行
  • Pro 版（coming soon）：多设备同步、高级手势、云端配置

这样既能收集意愿，又不影响当前免费体验。
