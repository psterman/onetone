校准输入框 · 更简单的三种 + 原三方案

还有更直白的吗？有。

框选对小白仍像「工具」。D 拖贴纸、E 鼠标到位按空格、F 你平时怎么点就怎么点 更接近日常：看得见落点、少学新手势、跨 App/CLI 仍用相对坐标。

更简单直观

原来的三方案

所见即所得 跨 App / CLI 小白首选候选

拖这颗「钉子」放到输入框上

开始后出现一颗大准星。按住拖到输入框正中，松手或点「就这」。像贴便利贴，不用学框选。

示意窗口
把钉子拖到右侧框
AGENT
拖动蓝点到输入框，再点「就这」

步骤

  1. 准星已出现（可再点「重置钉子」）
  2. 拖到输入框中央
  3. 点「就这」保存
拖动钉子对齐输入框…
零拖拽 跨 App / CLI 要会按一个键

鼠标移到框上，按空格

不框选、不拖钉。只把鼠标放到要打字的地方，按 Space 定住。真机可用全局热键，遮罩不抢鼠标。

示意窗口
移动鼠标到右侧
AGENT
鼠标移到输入框上，按 Space

步骤

  1. 点「开始」
  2. 鼠标移到输入框（本页内移动即可）
  3. 按空格锁定
尚未开始
几乎不用学 用已有习惯 CLI 也可：点进终端再确认

你先像平时一样点进输入框

不教新手势。用户自己点进框（和每天用的一样），再点「记住这里」。真机可读「当前焦点控件」中心；无 UIA 则记点击位置。

示意窗口
先点右侧输入框
AGENT
请先点进输入框（它会亮起）

步骤

  1. 点「开始记住」
  2. 像平时一样点输入框
  3. 框亮起后，点「记住这里」
尚未开始
原方案容错高

框住输入框，松手取底边中心

拖矩形圈住；可圈大一点。落点取底边中心。

示意
圈右侧
AGENT
拖动圈住输入框

步骤

  1. 开始框选
  2. 拖一圈
  3. 松手保存

粗圈 + 框内精点

先圈大概，再只在圈内点一下。

示意
先圈再点
AGENT

步骤

  1. 粗圈
  2. 框内精点

原方案靠 UIA

点附近，吸到控件中心

CLI / 无 Edit 的窗口较弱。

示意
点附近
AGENT
点输入框附近

步骤

  1. 开始磁吸
  2. 点附近

怎么选（含新方案）

方案一句话小白跨 App/CLI精度推荐
D 拖准星把钉子拖到框上很低强高产品默认
E 空格定住鼠标到位按键很低强高键鼠熟练者
F 先点进框用你平时的点法最低强中高引导最省事
A 框选圈起来低强中高备选
B 粗+精圈完再点中最强容错最高老失败时
C 磁吸点附近吸附低弱于 CLI靠 UIA增强项

更简单直观的默认：D（拖准星贴纸）。 文案就一句：「把蓝点拖到要打字的地方」。 失败个案再升级到 B；有 UIA 再叠 C。F 适合首次引导（「你先点一下，我们跟着学」）。
