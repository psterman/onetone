SoftPad mental model

保留能力，先分清「在改哪样东西」

杂糅不是功能太多，而是五个平级 Tab 把板上的键、整块板、迷你栏/灯效附属摆成同一层。用户心智应先选对象，再进细节。

现在（平级 Tab = 心智打架）

显示 · 样式 键位 · SoftPad 按键 用途 · Agent/场景 灯效 · Agent 反馈 迷你栏 · 另一块 UI

同一横条暗示「五件事同等重要、可随便跳」——实际主路径只有「给当前应用的板上键赋值」。

改成三个对象（能力全留）

对象用户一句话收纳现在的能力入口
① 板上的键 这块板上绑了什么、改哪个键 键位、找命令、本应用命令、录制快捷键、文本口令、生效范围 主路径 · 默认
② 整块板 板子怎么出现、长什么样 显示（大小/位置/出现时机）、用途里「这套板给谁用」的浅设置 中栏切换「整板」
③ 附属条 灯效和迷你栏怎么跟手 灯效、迷你栏（Agent 状态反馈） 整板里的子项，或顶栏次要入口

页面结构（习惯仍在最右）

预览 · 对象①的身体

点键 = 选中一条习惯

中栏 · 一次只改一个对象

此键 ① 整板 ② 附属 ③

「找命令」只在此键里点「更换命令」才打开

最右 · 本场景键位

命令菜单
语音输入
结束发送

＋ 新建键位

用途 / Agent 放哪（避免再平级）

  • 绑定应用留在顶栏（场景），不要再做一个叫「用途」的大 Tab 和键位抢戏。
  • Agent 灯效 / 迷你栏归对象③「附属条」——用户心智是「跟手的状态条」，不是「又一种键位」。
  • 本应用已有命令（你截图里的卡片）= 此键流程里的「从其它通道借用」，抽屉打开，不是第五个顶 Tab。

一句话心智

先选场景 → 再管板上的键（主）→ 偶尔调整板长什么样 / 附属条。 五个旧 Tab 变成「中栏对象切换」，能力不删，层级不抢。
