右侧怎么切

  1. 此键（选中键时默认）：名称、快捷键、录制、文本口令、生效范围 +「更换命令」
  2. 整板：显示 / 用途 / 灯效 / 迷你栏（原 Tab 迁到这里，不再和键编辑并排五 Tab）

「键位」Tab 取消作为常驻层；键位工作 = 预览 + 中栏「此键」+ 最右习惯列。

和按键 / 语音对齐

  • 场景在顶栏，不在预览里
  • 最右列 = 本场景动作目录（SoftPad 版，同按键/语音侧栏）
  • 中间偏左 = 编辑对象本体（板子）+ 改当前键
  • 新建 = 加一条绑定，不是新 Profile
