    六条硬规则

    1. 状态必带来源徽标。实心=官方信号，半实=官方 DB+启发式，空心=纯推断。hover 展开 evidence 路径、最后事件类型、观测时间。
    2. 过期显式降级。静默超阈值 → 整行"…前停止"，禁止永不变绿的假活。
    3. 看得见必须点得动。每个"等你"给一个就地可完成的最小动作；只能跳转的要明说。
    4. 零配置冷启动。无数据时显示"正在读取 N 个 agent 的本地记录"+骨架，不空白、不假装。
    5. 不新增主 CTA。台账行内按钮不与头条主 CTA 竞争；attention 下两者必须一致。
    6. 可折叠不可隐藏。安静态可折成一行汇总，不得消失——这是产品承诺。
