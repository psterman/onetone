已接线清单

—
    点矩阵里的一格 例如 Cursor × 口头指令，右侧只列出该格里的动作与触发方式。

    1. 先矩阵后列表

    总览用占用热力，不把所有应用的动作摊成一张长表。密度一眼可见缺口。

    2. 通道用小白话

    列名与识别页一致：按键 / 口头指令 / 软件自带 / 屏幕按钮 / 手势——不写内部 channel id。

    3. 一行动作可多通道

    同一动作若在按键+口头指令都有，清单里用多个小徽章标出；矩阵计数按通道各算一次。
