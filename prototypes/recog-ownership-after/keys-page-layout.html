现状问题

左轨「识别」六 tab 混搭

  • 口头 / Soft Pad / 手势不该在按键页可编
  • 触发键挤在左上，主画布被通道 picker 淹没
  • 用户以为「按键设置 = 全部识别配置」
  • 与命令中枢职责打架
新架构原则

触发置顶 · 按键家族 · 跨通道只读

  • 上：场景条 + 大触发键英雄区
  • 左：本页可编（听写键 / 我录的键 / 应用快捷键）
  • 中：选中项详情 + 录键 / 按法
  • 右：本场景「按键通道」动作列表
  • 底：其它通道只读芯片 → 中枢 / 深页
