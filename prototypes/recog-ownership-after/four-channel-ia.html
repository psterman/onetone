四个通道怎么理顺，四个页面怎么排

心智不是「四个设置产品」，而是：习惯场景 → 一条命令（做什么）→ 四种调用方式。 规划成 1 个命令中枢 + 4 个通道深页：中枢同屏配触发；深页只编本通道权威能力与高级项。

命令是一份 通道 = 触发器 中枢可写触发 深页不做混搭 摄像头不是第四产品

四通道触发

盘面 / 实体键 / 说法 / 手势
只回答「怎么叫到它」

Soft Pad

屏幕按钮

权威：盘面键位与布局

  • 绑定：哪颗屏幕键 → 哪条命令
  • 权威面：Pad 布局 / Mini / 外观
  • 中枢只选键位，不改编排
不做：在 Soft Pad 页伪装六条识别通道
实体按键

硬件触发

权威：录键 / 和弦 / 冲突

  • 绑定：Vol-、F9、鼠标侧键…
  • 权威面：录键、占用检测
  • 中枢只录/清触发键
不做：在按键页再编说法或手势
语音

口头说法

权威：说法 · 引擎 · 结束语

  • 绑定：同义说法列表
  • 权威面：麦克风、引擎、结束规则
  • 中枢只增删说法；引擎下钻
不做：在语音页再编识别键或盘面
摄像头

手势 / 在席

权威：手势 · 在席策略

  • 绑定：OK / 点头 / 摇头…
  • 权威面：预览、阈值、在席动作
  • 中枢只选手势；校准下钻
不做：把摄像头做成独立第四产品首页

2. 页面怎么规划（1 + 4，不是 4 并列）

侧栏入口收成「命令配置」；四通道深页降为二级权威编辑器

信息架构层级

L0
命令中枢（唯一主配置页） 左命令列表 · 中四通道触发卡 · 右检查器。同屏完成日常绑定。
L1
四通道深页（权威编辑器） Soft Pad / 按键 / 语音 / 摄像头 —— 只编本通道权威能力；跨通道只读引用 + 跳回中枢。
L2
高级 / Pro 子面 引擎资源、在席策略、盘面外观、校准 —— 从不出现在中枢主画布。

导航：改前 vs 改后

现在（并列四页）
  • 按键设置
  • 语音设置
  • Soft Pad
  • 摄像头
  • → 用户以为四个产品
规划后
  • 命令配置（中枢）
  • ↳ Soft Pad 深页
  • ↳ 按键深页
  • ↳ 语音深页
  • ↳ 摄像头深页
