IA 修正：对准 = 发送选项，不是平行视图
  1. 写什么（上）：库轨 + 编辑器 —— 管「注入哪段正文」。
  2. 发送选项（下）：怎么对准 —— 管「写入前如何落点」；叠在正文下方，因果是 写 → 发。
  3. 三策略共用一块舞台：说明动画与落点光点融合；仅「自动对准」显示光点与校准。
  4. 不做右栏平行卡：那会把「选项」抬成与「内容」同级，读起来像两个产品面。

平行双栏

左写什么 / 右怎么对准。对准被抬成同级视图，像第二张工作台。

上写下发 采用

正文库+编辑在上；发送选项（对准）叠在下。与「说一词 → 写入 → 发送」同序。

自动对准再写入

光点 = 落点。口令后点到该点再写入；对不上就取消。

  1. 1说出口令
  2. 2自动点到光点
  3. 3写入并发送

不对准，直接写入

焦点在哪就打到哪。最快，但旁边开着代码时容易误写入文件。

  1. 1说出口令
  2. 2立刻在当前焦点打字
  3. 3不对焦聊天框也会写入

防误写：未对准则跳过

聊天框没有光标就不写。口令仍识别，只是本轮不注入。

  1. 1说出口令
  2. 2检查是否已对准
  3. 3未对准 → 跳过，不写入
