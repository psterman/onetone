# OneTone 首页架构四版原型

这是独立于生产代码的首页架构比较器。四版共享同一组项目、Agent、来源质量、动作和状态数据，只改变首页的主交互模型。

## 打开

直接打开 `index.html`，或用静态服务器打开本目录。

- `?v=1..4`：续作台 / 一句话 / 动作牌桌 / 双栏驾驶舱
- `?state=idle|resume|running|waiting|dictating|degraded`
- 数字键 `1–4` 或方向键切换版本，`R` 重放入场动效

示例：`index.html?v=3&state=waiting`

## 四个方向

| 版本 | 主轴 | 适合 | 代价 |
| --- | --- | --- | --- |
| 续作台 | 单任务、恢复优先 | 日常打开后立刻接着做 | 对多 Agent 并行情况展示较少 |
| 一句话 | 语音与自然语言意图优先 | 不想理解设置和动作体系的用户 | 对已熟悉快捷操作的用户偏慢 |
| 动作牌桌 | 语义动作与四通道绑定 | 需要理解、配置和复用动作的用户 | 信息密度最高，学习成本更高 |
| 双栏驾驶舱 | 工作、阻塞、活动并行 | 同时监控多个信号的重度用户 | 小窗口下更紧凑，安静感较弱 |

## 共同架构约束

- 首页优先级：需要用户介入 → 可继续/进行中的工作 → 上下文动作 → 实际动作历史。
- 历史、项目记忆、连接与数据不再占用首页一级标签，改为上下文抽屉或设置子页。
- 四通道是同一语义动作的入口，不是四张并列功能卡。
- 每个状态只有一个视觉主操作。
- 数据块标明来源质量与更新时间；不可用时展示缺失原因，不虚构进度。
- 摄像头可以发起批准请求，但不能独自完成批准，必须跨通道确认。
