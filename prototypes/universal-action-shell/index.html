一个壳，两种打开方式

不把「选 Camera 动作」整页改成万能菜单。抽出同一套动作目录壳： 左应用场景 · 右动作 · 搜索 · 通道筛选。顶部用模式切换区分 绑定（配置映射）与 调用（立刻执行）。

保留绑定身份 从手势/按键进来时，标题仍写「选 Camera 动作 · 五指张开」，主按钮是「绑定」。
另开调用入口 托盘 / Soft Pad / 快捷键打开同一壳，模式锁定为「调用」，主按钮是「执行」。
目录只抽一次 场景列表、通道过滤、搜索、动作行结构共用；勿复制第三套 picker。

怎么看这个原型

点顶部 BIND / RUN。壳布局不变，变的是标题、主按钮、是否显示「不执行」、动作行右侧 CTA。

建议接入路径

  1. Camera / Keys 绑定 → mode: bind
  2. 托盘「动作目录」→ mode: run
  3. Soft Pad 长按空白 → mode: run
