自己录 · 原型：新建自定义快捷键

不是「改左侧当前键的动作」，而是收录一条新的可命名快捷键（名称 + 组合键 + 口令），保存后进「我的常见」。 左侧 SoftPad 键方案在录制过程中保持不变。

旧理解（不要） 选中数字 7 → 自己录 → 重录当前「新建对话」的 chord → 改了当前键方案。
新理解（要） 自己录 → 填名称（可选口令）→ 点「录制按键」弹出听键页 → 确认后自动进常见。左侧键不动。

推荐路径
  1. 填名称（可选口令）→ 点「录制按键」→ 二级听键页 → 按下组合键 → 点「用这个键」
