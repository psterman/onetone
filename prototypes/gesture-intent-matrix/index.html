现在

口头指令 = 口令条目表

右侧列出「开始听写 / 发送 / 取消 / Agent…」，点一条去录快捷键。引擎往往全天候挂着等这些固定说法。

  • 心智：选一条预制口令
  • 文本：封闭词表，不是开放语音文本
  • 与启动键关系弱，靠说唤醒
升级后

口头指令 = 按键激活的收听方案

按法绑「口头指令」→ 按下后 OneTone 开窗，专注接收用户语音并转成文本；预制口令变成窗内可选增强，不再是主界面。

  • 心智：打开听我说 → 出文本
  • 文本：开放识别，再交给 OneTone
  • 与启动键强绑定，按需开麦
  • 悬浮栏：只服务口头指令；语音输入不另做听写 UI
