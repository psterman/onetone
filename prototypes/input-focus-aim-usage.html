InputFocusAim · naming + UI

名称要能望文生义，选项要说清后果

内部仍用 auto / none / probe；用户看到的是「会做什么 / 失败怎样」。不要写「链式」「探测」这类实现词。

改名对照

旧（难懂）新（望文生义）失败时
自动链式 先对准，再填入 对不准 → 取消，不乱填
不对准 直接填入 不检查；你已点好框
仅探测 只在已对准时填 光标不在框里 → 取消

② 先对准，再填入

对准成功后才 Text + Enter。

推荐默认：「先对准，再填入」。高级用户才选「直接填入」。

UI 别这样

  • 下拉里塞「链式 / 探测 / UIA」
  • 只有短名、没有「失败会怎样」
  • 每个通道再各勾一遍

UI 要这样

  • 三张卡片：标题 = 动作，副文 = 适用场景
  • 每张写清失败后果
  • 一处设置，全通道继承
