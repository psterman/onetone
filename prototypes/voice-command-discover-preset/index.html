三种做法

结论：应该预置。
预置的是收听窗里的起步命令（发送 / 取消 / 新建 / 继续…），不是 Keys 左栏再摆一张大目录。 长期调整：芯片「改」→ 改说法；「＋」加自己的；场景切换可换另一套起步包。
起步包示例 · Cursor 场景
推荐一体旅程 发现 → 激活 → 首测 → 微调
① 发现：三处同一句话 Keys「口头指令」页 · Soft Pad 底条 · 绑按法后的轻提示 —— 都说「激活后进入语音管理」。
② 激活：按法或麦键，同一会话 不要求用户先配完词表。绑一次双击，或直接点麦，立刻开收听窗。
③ 首测：窗内亮起步包 4～6 条场景命令可说可点。第一次成功不靠灵感，靠预置。
④ 长期：改说法 / 关 / 加，不回退成大目录首页 高级「命令库」可从芯片「改」或设置深处进入；主路径始终是模式开关 + 起步包。
产品口径：口头指令 = 语音管理模式（按需开麦）。 预置命令 = 模式内的起步工具，服务测试与日常，不重新变成 Keys 主列表。
