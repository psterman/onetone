# Soft Pad 状态灯 v16 原型

**左预览 | 右配置**锁定。配置单位 = **应用**（先选 Agent，再配该应用的虚拟键盘 / 灯效与浮窗）。

## 三个子页（已取消「名单与接入」）

1. **灯效匹配** — 顶部：当前 Agent 接入（Pad / 状态源）；下：氛围灯 · 按键灯  
2. **显示数据** — 只管设置页**数字**（账号/额度/重置）+ API 候补  
3. **迷你栏** — 完整体/精简态、用量 pill、**灯条上亮谁**（原顶栏名单）
