# 视觉态分阶段规则

> Activation Hub 在激活窗口内推进 5 个阶段。迷你栏的图标位、颜色、动效
> 严格按这个规则渲染。

## 阶段总览

```
                    ┌──────────────────────────────────────┐
                    │ IDLE（默认）                          │
                    │  • 图标全灰                           │
                    │  • 不显示倒计时                       │
                    │  • 占用空间 = 单行最小                 │
                    └──────────┬───────────────────────────┘
                               │ voice-wake.triggered
                               ▼
        ┌──────────────────────────────────────┐
        │ LISTEN（0-3s / 直到用户开始说话）     │
        │  • 🎙 mic 蓝，脉冲（脉冲周期 1.2s）   │
        │  • 👀 camera 灰                       │
        │  • 🧠 think 灰                       │
        │  • 显示倒计时（如 12s）               │
        └──────────┬───────────────────────────┘
                   │ camera 启动 + 检测到人脸
                   │ （或 800ms 后自动进入）
                   ▼
        ┌──────────────────────────────────────┐
        │ WATCH（持续监听视觉/体态）              │
        │  • 🎙 mic 蓝，脉冲                    │
        │  • 👀 camera 绿，常亮（不再脉冲）     │
        │  • 🧠 think 灰                       │
        │  • 倒计时继续                         │
        └──────────┬───────────────────────────┘
                   │ visual-agent 触发动作 / 用户说命令
                   ▼
        ┌──────────────────────────────────────┐
        │ THINK（动作执行中）                    │
        │  • 🎙 mic 蓝                          │
        │  • 👀 camera 绿                       │
        │  • 🧠 think 紫，脉冲（脉冲周期 0.6s） │
        │  • 倒计时继续                         │
        └──────────┬───────────────────────────┘
                   │ commit / cancel / timeout
                   ▼
        ┌──────────────────────────────────────┐
        │ DONE（短暂反馈，800ms）                │
        │  • 全图标 ✓ 绿色 0.5s                 │
        │  • 然后 fade out                      │
        └──────────┬───────────────────────────┘
                   │ 800ms 后
                   ▼
                IDLE（回到默认）
```

## 软关闭提示（Soft Close）

当 `remainingMs < softCloseMs`（默认剩 5s）时：
- 🎙 mic 颜色从蓝 → 橙
- 倒计时数字从普通色 → 红色
- 频率加快：脉冲周期从 1.2s → 0.4s

目的：给用户"还剩 5 秒"的视觉预警，避免突然中断。

## 颜色规则

| 状态 | 颜色 | 颜色值（HEX/RGBA） | 备注 |
|---|---|---|---|
| IDLE | 灰 | `rgba(125, 137, 152, 0.4)` | `--overlay-muted` |
| LISTEN mic | 蓝 | `rgba(0, 163, 255, 0.85)` | 复用现有 `--overlay-led-idle` |
| LISTEN mic 软关闭 | 橙 | `rgba(255, 165, 0, 0.9)` | 警告色 |
| WATCH camera | 绿 | `rgba(34, 197, 94, 0.85)` | 视觉接管 |
| THINK think | 紫 | `rgba(168, 85, 247, 0.9)` | AI 处理中 |
| DONE | 绿（实色） | `rgba(22, 163, 74, 1)` | 复用现有 success 色 |
| ERROR | 红 | `rgba(220, 38, 38, 0.95)` | 复用现有 error 色 |

## 动效规则

| 元素 | 动效 | 时长 | 缓动 |
|---|---|---|---|
| 图标进入激活 | scale 0.85 → 1.0 + opacity 0 → 1 | 220ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` (回弹) |
| 脉冲（listen mic / think）| scale 1.0 → 1.15 → 1.0 + opacity 0.6 → 1 → 0.6 | 1200ms（listen） / 600ms（think）| `ease-in-out` |
| 软关闭 | 同上但周期 400ms | — | — |
| 阶段切换 | 旧图标淡出 + 新图标淡入，间隔 80ms | 200ms | `ease-out` |
| 退出激活 | scale 1.0 → 0.85 + opacity 1 → 0 | 180ms | `ease-in` |
| DONE 完成态 | scale 0.85 → 1.1 → 1.0 + 颜色切换 | 500ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| 倒计时数字 | 数字变化时翻牌（rotateX 90° → 0°） | 240ms | `ease-out` |

## 倒计时显示规则

- **显示位置**：迷你栏最右侧，展开按钮前
- **显示格式**：`{N}s`（如 `12s`）
- **显示时机**：仅在 `listen / watch / think` 阶段显示
- **隐藏时机**：`idle / done` 阶段隐藏
- **软关闭样式**：
  - 倒计时数字变红 + 轻微缩放（1.0 → 1.05）每 1s
  - mic 图标变橙

## 错误态处理

- `activation:error` 收到时（非 fatal）：
  - 触发错误的图标（如 camera）变红 + 闪烁 2 次
  - 其他图标正常继续
- `activation:error` 收到时（fatal）：
  - 立即进入 DONE 阶段
  - 迷你栏显示 `出错了 · {message}` 一行
  - 800ms 后回到 IDLE

## 视觉一致性原则

- 沿用 OneTone 现有 `--overlay-led-idle: rgba(0, 163, 255, 0.45)` 的色系
- 不引入新字体、新图标风格
- 图标使用 14×14 圆形 chip（与现有 `overlay-mini__agent` 同尺寸）
- 动效沿用 `motion.css` 现有的 `ease` / `cubic-bezier` 风格

## 不显示的规则

- **IDLE 阶段**：3 个图标位可见但都灰、不脉冲、不显示倒计时
- **DONE 阶段**：3 个图标都打勾（✓ 绿色），不显示倒计时
- **窗口期外**：3 个图标位占位但不渲染任何内容（保持布局稳定，避免抖动）
