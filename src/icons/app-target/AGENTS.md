# Agent & Provider Icon Manifest

> **Source of truth** for SoftPad / mini overlay / status light icons.
> Runtime reads `src/icons/app-target/<name>.png` (see `src/js/features/agent/agent-install-orchestrator.js`).

## Layout

| Folder | Purpose | Used by |
|---|---|---|
| `src/icons/app-target/` | **Agent icons** (CLI / IDE / desktop tools that emit lifecycle events / status lights) | `agent_install_orchestrator.js` — soft pad chip, mini bar, focus window |
| `src/icons/provider/` | **LLM provider icons** (services with quota API) | (new) SoftPad "用量" page, mini usage pill dropdown |
| `src/icons/ime/` | Input-method icons (Sogou / WeChat / iFlytek / Zhipu…) | **Not agents** — voice-pilot input fallback |

## Status legend

- ✅ **real** — official brand asset or hand-illustrated
- 🟡 **placeholder** — generated by `scripts/_organize_agent_icons.py` (colored square + initials); replace before shipping the corresponding feature
- ⚠️ **legacy / alias** — kept for back-compat, do not use in new code

## Adding a new icon

1. Drop `<name>.svg` (preferred) into the right folder
2. Optionally drop `<name>.png` (64×64 minimum) for runtime
3. Update the manifest above (mark ✅ real, replace 🟡 placeholder)
4. If the agent needs SoftPad status lights, add to `soft_pad_runtime/model.rs::AgentKind` and follow `docs/soft-pad-client-hooks-impl.md` §公共改动清单
5. If the provider needs quota, add to `provider_usage.rs::ProviderId` and follow the Slice A plan

## Regenerating placeholders

```powershell
python scripts\_organize_agent_icons.py
```

The script **never overwrites an existing PNG** — only writes SVGs and PNGs that don't exist yet. To regenerate a placeholder, delete its PNG first.

Copilot / Gemini marks (not letter tiles):

```powershell
python scripts\_draw_copilot_gemini_icons.py
```

Cline / OpenCode / Aider (official assets):

```powershell
python scripts\_import_cline_opencode_aider_icons.py
```

## Conventions

- **Square, rounded corners** (rx ≈ ¼ of width) — matches existing app-target style
- **Solid brand color** as background, white initials on top
- **No drop shadow, no gradient** — these get composited on soft-pad mini bar
- **Naming**: lowercase, hyphenated, no spaces — `<product>.svg` / `<product>.png`
- **Aliases** (workbuddy ↔ codebuddy, moonshot ↔ kimi): keep both files, mark the secondary as ⚠️ alias in the manifest
