voice-pilot · M1 集成指南 HOME v9

把 home-v9.css + home-v9.js 接进现有项目，照着下面 5 步操作。整页估计 30-60 分钟。

01放置文件

把两个文件放到对应位置： 
src/
├── css/
│   ├── app.css         ← 已有 · 保留不动
│   └── home-v9.css     ← 新增 ← 就是这个文件
└── js/
    ├── app.js          ← 已有 · 保留不动
    └── home-v9.js      ← 新增 ← 配套 JS

02在 src/index.html 引入 2 处

2.1 在 <head> 里引入新 CSS

找到现有的 <link rel="stylesheet" href="css/app.css" />，在它后面加一行：

<link rel="stylesheet" href="css/app.css" />      // 已有
<link rel="stylesheet" href="css/home-v9.css" />  // 新增
为什么在后面：home-v9.css 里覆盖了 --primary 等 token，后引入的优先级更高。这样不用动 app.css 也能换品牌色。

2.2 在 <body> 末尾引入新 JS

找到现有的 <script src="js/app.js"></script>，在它后面加一行：

<script src="js/app.js" defer></script>       // 已有
<script src="js/home-v9.js" defer></script>  // 新增

03改造 header 替换 1 个 class

找到现有的 <header class="app-header">，把 class 改成： 
<header class="app-header">
<header class="app-header app-header-rev">

CSS 就会自动套用新样式，HTML 结构不动。

注意：如果你的 JS 里有 document.querySelector('.app-header') 监听点击事件，不需要改 JS，新 class 是叠加的不是替换。

05接上现有数据流 JS 桥接

把你现有 app.js 里更新首页状态的函数，改成同时调用 vp9 API：

// 现有代码（举例）
function onDictationStart(){
  document.getElementById('homeStatusTitle').textContent = '正在听';
  document.getElementById('homeStatusIcon').classList.add('is-active');
}

// 改成
function onDictationStart(){
  window.vp9.updateState('DICTATING');
  // 旧代码保留作为 fallback，不冲突
  document.getElementById('homeStatusTitle').textContent = '正在听';
}

// 识别到新字符时
function onPartialText(text){
  window.vp9.setText('#vp9LiveText', previousFinal, text);
  document.getElementById('vp9Chars').textContent = text.length + ' chars';
}

// 识别完成（断句）
function onFinalText(text){
  window.vp9.typewrite('#vp9LiveText', text, 50);
  previousFinal = text;
}

// 引擎离线
function onEngineOffline(){
  window.vp9.updateState('ERROR');
}

回滚方案

任何一步出问题，3 秒钟回滚：
  1. 删掉 src/index.html 里新引入的两行 <link> 和 <script>
  2. 删掉 .home-zone 里粘进去的那段 vp- 区块
  3. 把 <header class="app-header app-header-rev"> 改回 <header class="app-header">

或者直接 git checkout src/index.html。
