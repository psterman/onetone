## 评估：React Islands 渐进迁移方案
- 用户提交一份 React Islands 渐进迁移方案要求评估；我基于代码实查逐条核实。
- 已核实属实：双状态/重挂载风险是现存隐患（config-persist.js 有「假死/remount storm」注释 + mvpInitHeavyRemountBlocked 守卫）；settingsPanelBasic/Keys/VoiceWake 挂载点真实存在；OneToneIpc.invoke 已用；render-loop.js 整树刷新 + __vp_render_hooks__ 分发。

- 补充硬伤：①data-i18n 自动 sweep 会覆盖岛内 React 文本；②shadcn Dialog/Dropdown/Toast 走 portal 逃出 .ot-island，Tailwind prefix 不够；③home/workbench 仍是最大 UI 面，若长期留 legacy 则真实收益低于 70%；④构建产物落点（写回 src/ vs dist/）需定标 + gitignore；⑤未提冒烟测试锁纪律。
- 结论：方案采纳为默认架构；首岛选 Basic 设置面板；render/mvp_init 与 React root 所有权是必须钉死点。
