# ClipSharp 4-in-1 卷笔刀 · 产品概念与 ID 设计

> 命名建议：ClipSharp / 卡扣卷笔刀 / 笔伴侣 / PencilMate
> 产品定位：紧凑型桌面文具 · 一物四用 · 学生与办公人群

---

## 一、核心设计理念

把"卷削 + 卡扣 + 停靠 + 橡皮"四个原本分散的桌面功能压缩到 **58 × 26 × 21 mm** 的笔形块状结构里，让一支普通铅笔"戴"上它之后：

- **不丢** —— 卡扣结构让卷笔刀始终"挂"在铅笔上
- **立得住** —— 加权底座让笔 + 卷笔刀组合稳稳立在桌面
- **不脏** —— 卷削时铅笔屑被透明屑盒收纳，不掉桌面
- **随时擦** —— 底部弹出式橡皮擦，伸手就能擦

**设计原则**：把"卷笔刀"从"放在笔筒里的工具"重新定义为"长在铅笔上的附件"。

---

## 二、四大功能模块

### 模块 A · 卡扣固定（Attach）
| 维度 | 参数 |
| --- | --- |
| 结构 | 侧面弹簧夹（侧夹式，U 形开口朝上） |
| 适配铅笔直径 | 7.0 – 8.5 mm（覆盖中国 / 欧洲 / 美国主流标准铅笔） |
| 卡持力 | 0.8 N – 1.5 N（既不滑落，也不卡死难拔） |
| 寿命 | 弹簧 ≥ 10,000 次夹持循环 |
| 材质 | POM / PC + SUS304 弹簧钢丝 |

**核心价值**：铅笔 + 卷笔刀 = 一个整体，不会"刀在桌上，笔在手里"。

### 模块 B · 桌面停靠（Dock）
| 维度 | 参数 |
| --- | --- |
| 底座形态 | 圆角矩形平板底，略宽于主体 2 mm 形成"裙边" |
| 配重 | 不锈钢底板，重量 ≥ 8 g |
| 重心 | 底座中心，确保铅笔垂直插入时倾角 < 2° |
| 适配笔长 | 100 – 190 mm 标准铅笔（不含彩铅加长款） |

**核心价值**：圆柱铅笔的"天然痛点"——容易滚走 —— 被一个底座解决。

### 模块 C · 卷削（Sharpen）
| 维度 | 参数 |
| --- | --- |
| 刀片 | 单孔螺旋合金钢刀片（兼容 7 mm 笔杆） |
| 刀片角度 | 23°（锐角，削尖效率高） |
| 屑盒 | 透明 PC 抽屉式，约 8 ml 容量（≈ 30 次削尖） |
| 屑盒锁 | 卡扣 + 滑动双锁，防止意外脱落 |
| 寿命 | 合金刀片 ≥ 500 次削尖，可单独更换 |

**核心价值**：透明屑盒可视化剩余容量，避免满溢弄脏书包。

### 模块 D · 橡皮擦（Erase）
| 维度 | 参数 |
| --- | --- |
| 位置 | 主体底部侧推式 |
| 推杆 | 棘轮推进，每次按压推出 1.5 mm |
| 橡皮 | 直径 12 mm PVC-free 高级橡皮 |
| 寿命 | 单块橡皮 ≥ 200 次擦除 |

**核心价值**：不需要另外带橡皮，铅笔 + 刀本身就够。

## 三、ID（工业设计）语言

### 形态语言
- **主体**：圆角矩形块状（cuboid with radius），58 × 26 × 21 mm
- **顶部**：与水平面成 23° 斜面的卷削口，引导铅笔自然入削
- **侧面**：弹簧卡扣从主体伸出一条 U 形夹臂，夹臂内贴防滑硅胶
- **底部**：略宽的金属配重底座，形成"上窄下宽"视觉稳定感
- **整体 R 角**：外轮廓 R3 mm，分模线 R1 mm，触感柔和不硌手

### 颜色策略（6 色 SKU 矩阵）
| 色号 | 名称 | 目标人群 | 备注 |
| --- | --- | --- | --- |
| 01 | 薄荷绿 Mint | 学生 / 文艺青年 | 主推色，治愈系 |
| 02 | 樱花粉 Coral | 女性办公 | 高识别度 |
| 03 | 哑光黑 Matte Black | 商务 / 男性办公 | 高级感 |
| 04 | 天空蓝 Sky Blue | 中性 / 学生 | 男女通吃 |
| 05 | 薰衣草紫 Lavender | 女性学生 | 流行色 |
| 06 | 米白 Cream | 极简 / 文创 | 高级礼品向 |

外主体为塑料原色，**弹簧夹 + 底座 + 刀片**统一深灰（Pantone 426 C），保证识别度。

### 表面处理
- 主体：**细磨砂哑光**（不沾指纹）
- 金属底座：**拉丝 + 阳极氧化**（耐刮）
- 弹簧夹：注塑纹理（增加摩擦力）
- 屑盒：**高透明 PC**（透光率 ≥ 92%）

### Logo 摆放
- 主体正面右下角 8 × 8 mm 凹印品牌 Logo
- 不喧宾夺主，符合"工具的克制美学"

## 四、用户体验亮点（UX Highlights）

1. **单手操作**：食指推铅笔入削，拇指按下橡皮棘轮，单手完成全部功能
2. **盲操作友好**：23° 斜面 + 弹簧夹导引，无需对准
3. **视觉反馈**：透明屑盒让你一眼看到"快满了"
4. **情感化设计**：彩色外壳 + 金属底座的混搭，办公桌上一抹亮色
