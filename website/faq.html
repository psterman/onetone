语音与麦克风

为什么检测不到麦克风？
  1. Windows：设置 → 隐私 → 麦克风 → 允许桌面应用访问。
  2. OneTone：设置 → 语音 → 刷新设备列表。
  3. 硬件：USB 麦克风重插；蓝牙麦在系统声音设置里设为默认输入。
  4. 区分场景：一声语音唤起与输入法听写都需要麦——若按键能唤醒输入法但无声音，多半是输入法没拿到麦克风权限。

先在 Windows「声音」里试麦，再在输入法里试听写，最后才测一声。

为什么会录到电脑声音？

在设置 → 声音 开启「录音时自动降低系统声音」。在 Windows 声音设置里禁用「立体声混音」类录音设备。优先使用耳机麦克风，避免扬声器回授。

说了唤醒词没反应？
  1. 确认已在设置 → 语音 开启语音唤起（轻量或离线模式）。
  2. 唤醒词需与设置里勾选的短语一致，尽量在安静环境清晰说出。
  3. 轻量模式依赖 Windows 语音识别，需已安装中文语音包。
  4. 刚结束上一轮听写时，需等几秒再说唤醒词。

触发有反应，但输入法没被唤醒？

说明一声收到了触发，但模拟的语音快捷键不对，或输入法未就绪。

  1. 在输入法设置里确认「语音输入 / 听写」的快捷键（如 RAlt、Ctrl+Shift 等）。
  2. 在 OneTone 设置 → 按键，重新录入同一组合，或点输入法预设自动填入。
  3. 录快捷键前先退出听写状态；在普通英文输入状态下录制。
  4. 在记事本里不用一声，手动按该快捷键，确认语音条会出现。

输入法

百度输入法怎么设置快捷键？

在百度输入法设置里查找语音快捷键（常见 Alt+A，部分版本为 F2/F1）。在 OneTone 设置 → 按键录入同一组合，或选择百度预设。

微信 / 搜狗输入法可以用吗？

可以。在对应输入法里确认语音快捷键，在 OneTone 设置 → 按键录入同一组合，或点选输入法预设。

按键与方案

为什么我按了没反应？
  • 软件有没有开 — 看系统托盘，一声图标要在运行
  • 按键有没有录对 — 设置里「你的键」和测试时按的是同一个吗？
  • 输入法快捷键对不对 — 在记事本直接按输入法的激活键测试
  1. 软件在运行吗？看托盘「一声」图标；若显示「监听已暂停」，点首页恢复监听。
  2. 键录对了吗？设置 → 按键，点「测试发送」或在记事本按同一触发键。
  3. 输入法激活键能用吗？不用一声，在记事本直接按你录的语音快捷键，看是否出现语音条。
  4. 仍无效：设置 → 运行状态查看最近按键；先在记事本测试，避开全屏游戏。

顶部显示「监听已暂停」？

暂停时所有触发键都不会响应。在首页点「恢复监听」，或托盘菜单恢复。若正在录键，先结束录制再测试。

「使用场景」和列表里点选有什么区别？

一声用「当前场景」决定语音唤醒、结束词和按键提示；在列表里点一条只是浏览编辑，不会自动切换运行时。

  1. 设置 → 使用场景：左侧点选场景可改按键、语音覆盖、目标应用。
  2. 要让语音和 Coach 提示跟着变，需点 设为当前场景（或首页方案切换器）。
  3. 全局麦克风、引擎、默认唤醒词在 全局语音；单场景可在「语音」Tab 做稀疏覆盖。

按键设错了，怎么改回来？

从轻到重，按需选择：

  1. 只录错一个：设置 → 按键 → 重新点「录触发键」或「录语音快捷键」。
  2. 多套方案搞混：只启用一个方案；或设置 → 恢复与维护 → 回收站恢复旧方案。
  3. 全部重来：设置 → 恢复与维护 →「清除全部映射」。

录键失败 / 提示「未能识别该按键」？

这是录制被拒绝，不代表键盘坏了。常见原因与处理：

  • 换一颗键：音量键、鼠标侧键、F 区单键通常最稳。
  • 录触发键时不要点桌面、开始菜单；避免只按 Ctrl/Alt/Shift 等修饰键。
  • 组合键：先按住修饰键，再按主键，等界面显示完整组合后松开。
  • 录语音快捷键前，先退出输入法的听写状态。
  • 仍失败：重启一声；少数外设需先打开该外设配套软件。

提示按键冲突 / 方案被自动关掉？

两个已启用方案使用了相同触发键（或相同外设物理键）时，一声会停用其中一个，避免乱触发。处理：只保留一个启用的方案，或给不同方案换不同的触发键。顶部「冲突」提示可点进方案列表查看。

测试发送失败，但实际按键好像有反应？
  1. 测试前先点开记事本或聊天框，让光标在输入位置。
  2. 确认未暂停监听，且未处于录键状态。
  3. 若测试成功但外设不触发，检查触发模式是否为「长按」——轻按无效，需按住约 0.5 秒。
