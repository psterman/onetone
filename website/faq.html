常见问题

按你遇到的问题往下找，先排第一层再读详细说明。

为什么我按了没反应？
  • 软件有没有开 — 看系统托盘
  • 按键有没有录对 — 设置里和测试时同一个键吗？
  • 输入法快捷键对不对 — 在记事本直接按输入法的激活键测试

1. 软件在运行吗？ 看托盘「一声」图标，暂停则恢复监听。

2. 键录对了吗？ 设置 → 按键，在记事本按同一触发键测试。

3. 输入法激活键能用吗？ 不用一声，在记事本直接按你录的激活键，看输入法是否进入听写。

4. 仍无效： 打开运行状态；先在记事本测试，避开全屏游戏。

为什么检测不到麦克风？

设置 → 隐私 → 麦克风，允许桌面应用。设置 → 语音 刷新列表。USB 重插；蓝牙设为默认输入。

Allow mic for desktop apps in Privacy. Refresh device list in Settings → Voice. Replug USB; set Bluetooth as default.

为什么会录到电脑声音？

开启「录音时自动降低系统声音」。关闭立体声混音录音设备。优先用耳机麦。

Enable lower system volume while recording. Disable Stereo Mix. Use a headset mic.

百度输入法怎么设置快捷键？

百度设置里查语音快捷键（常见 Alt+A，部分版本 F2/F1）。在一声设置 → 按键录入同一组合。

微信 / 搜狗输入法可以用吗？

可以。在输入法里确认语音快捷键，在设置 → 按键录入同一组合。

Yes. Confirm the IME voice shortcut and record the same combo in Settings → Keys.

怎么恢复默认设置？

设置 → 通用 → 恢复默认。或删除 %APPDATA%\onetone\config\settings.json（更新不会覆盖）。

Settings → General → Reset. Or delete settings.json under %APPDATA%\onetone\config\ (updates preserve it).

还是不行，怎么反馈问题？

附上 Windows 版本、一声版本、触发键与语音键、输入法、复现步骤。提交问题

Include Windows & app version, keys, IME, steps. Report issue
