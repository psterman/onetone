方案隐喻优点代价
A 单卡片分区一张发票三个栏目实现最轻；与现有 shell 最接近；不增加新交互关联感靠渐变+去边框，叙事弱于 B/C
B 叙事脊柱流水线 场景→此刻→通道小白最易理解「上面选、中间用、下面是配置」；左轴强化因果多一层步骤 UI；略占横向空间
C 展开容器选中场景的「工作区」关联最强：Hero+通道明确属于当前场景；切换时整块 morph展开动画与高度变化；rail 与 expand 要防重复（选中项只在 expand 头出现）

推荐：要懒人落地选 A（改 CSS 为主）；要教育用户选 B；要「主题统治感」最强选 C。
