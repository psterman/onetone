用户只需解决 3 件事:这是什么 · 我能干什么 · 干了以后怎么样 · 其他都藏起来
👤 小白视角(本次推荐) 🛠️ 架构师视角(上一版)

设计原则

把"工程师视角"全部下沉到高级菜单,主界面只回答小白用户的 3 个问题。所有调参、6 主题网格、模型管理、声学口令都隐藏到 `···` 菜单里。

① 这是什么
"按一下 · 说话 · 自动上屏"
- 一堆状态徽章 + pills + 波形 + 习惯
+ 一行大字 + 1 个蓝色大按钮
② 我能干什么
"4 个常见场景卡"
- 6 主题网格 + 引擎选择 + 阈值调节
+ 写邮件 / 跟 AI 说 / 走路记笔记 / 说完就发
③ 干了以后怎么样
"实时时间线 + 4 个数字"
- 进度条 + busy state + 错误堆栈
+ 这次说的话 / 节省时间 / 准确率 / 上次成功

联动说明 · 5 步走完一次完整流程

小白用户从打开 OneTone → 按键 → 说话 → 出结果 → 看效果,全程不超过 5 步,每步都有视觉反馈。

典型流程:在 Cursor 里跟 Claude 说话

1️⃣
Step 1
看到主界面
2️⃣
Step 2
按 F8(大蓝按钮)
3️⃣
Step 3
对着麦克风说
4️⃣
Step 4
"发送"两个字
5️⃣
Step 5
看"干了以后怎么样"标签页

↑ 1️⃣ 和 5️⃣ 在主界面(可见)· 2️⃣ 3️⃣ 4️⃣ 是一次操作(连按带说,3 秒搞定)· 用户全程不需要进 settings

藏起来的东西 · 在哪儿找

所有"上一版架构师视角"的元素,都收到主界面右上角的 ··· 菜单里,需要的人能找到,不需要的人永远看不到。

藏起来的内容 藏在哪儿 小白什么时候会用到
语音控制台(6 主题网格)··· → 语音控制台想换引擎、调麦克风、关掉离席检测
Settings 语音设置(模型/样本/阈值)··· → 设置 → 语音想下载新模型、录新样本
状态徽章 / 调试日志 / 冷却时间··· → 诊断怀疑出问题了,想看为什么
习惯 / 场景管理··· → 习惯想给不同应用(邮件/聊天)配不同设置
摄像头 / 美颜 / 离席检测··· → 高级 → 摄像头想用离席自动静音
