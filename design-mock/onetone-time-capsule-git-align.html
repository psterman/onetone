  • P2 Agent Round / preSend（要产品确认才做）

一句话

Git 层已可宣称「对齐大半」（约 85% 语义）。 若目标是「双端同仓读同一套 tip」或「发送前自动点」，才需要动 ref 布局与 Agent Round——那是产品增量，不是迁移阻塞。
