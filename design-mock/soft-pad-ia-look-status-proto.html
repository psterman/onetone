先梳清 Agent / 样式，再立目录

截图里的两大标签装的不是对称能力：一边接灯与读数，一边管出现与映射，却又共用灯效/迷你栏。下面先盘点 → 定 IA → 可点原型：设置左栏独立 Agent，虚拟键盘只剩绑键。

现状 · Agent 3 子页

对应截图左栏。真实职责是「接上 Agent + 看状态」，却和样式抢灯/迷你栏。

子页装了什么
灯效匹配 虚拟键盘开关 · Hook 接入 · 氛围灯 · 按键灯（含高级）
显示数据 当前读数 · 预览条摘要开关 · API 额度 / Cursor 本地统计
迷你栏 谁在忙 · 听你说话 · 快捷钮 · 浮窗形态（与样式重复）

现状 · 样式 4 子页

对应截图右栏（当前选中）。名字像皮肤，实际混了出现时机、键用途、灯、迷你栏。

子页装了什么
何时出现 显示方式（跟应用/置顶/迷你条/不显示）· 聆听口令 · 外观皮肤
动作键 AG 用途 · Soft Pad 映射 · 数字键占用 · 方向栏
灯效 与 Agent「灯效匹配」同一套氛围灯/按键灯（无接入卡）
迷你栏 与 Agent「迷你栏」同一渲染器

重复与错位

问题说明处理
灯效双入口Agent·灯效匹配 ↔ 样式·灯效只留 Agent 目录 · 灯效
迷你栏双入口两边同一 renderAgentMiniPanel只留 Agent 目录 · 迷你栏
何时浮出双文案样式「显示方式」≈ 迷你「何时浮出」并入样式 · 何时出现（一处）
动作键不像「样式」管 AG/数字键行为，属绑键规则迁回虚拟键盘顶条
显示数据无对偶仅 Agent 有Agent 目录 · 数据
外观皮肤埋在何时出现用户找「样式」却点到出现时机并入 Agent · 样式（皮肤+出现）

构建原则

按「我想改什么」分桶，不按历史 tab 名。虚拟键盘 = 动作面；Agent = 设置左栏独立目录（配置类，不进首页四通道）。

Agent ×3 样式 ×4 → 虚拟键盘 · 绑键 + 动作键顶条 Agent · 灯效 | 数据 | 样式 | 迷你栏
新位置子页迁入内容用户一句话
设置 → Agent
独立目录		 灯效 接入/开关（短卡）+ 氛围灯 + 按键灯 灯怎么亮、跟谁匹配
数据 当前读数 · 预览摘要 · 额度/本地统计 条上显示哪些数
样式 何时出现（唯一）· 外观皮肤 · 聆听口令 何时露、长什么样
迷你栏 谁在忙 · 听你说话 · 快捷钮 · 细条/完整键盘 浮窗条上有什么
设置 → 虚拟键盘 主面 + 顶条 键位绑定；顶条：动作键 / AG 用途 / 数字键占用 这颗键干什么
为何目录就叫 Agent（不用「监视」）

你要管的是 Agent 相关能力整包（灯、数据、样式、迷你栏）。左栏文案与产品对象一致；二级再用「灯效 / 数据 / 样式 / 迷你栏」拆开，避免再出现「Agent | 样式」两大标签对打。
