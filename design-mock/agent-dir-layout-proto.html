Layout proto · Agent vs Soft Pad chrome

Agent 用「顶栏 + 表单」，不用半屏键盘

虚拟键盘可以左预览右绑键；Agent 独立目录若照搬同一壳，心智又变回「还在改 Soft Pad」。下面对照错误壳与推荐壳，并写清原因。

不采用

左半屏数字键盘 + 右上标签 + 右下详情

这是 Soft Pad 动作面的壳。搬进 Agent，目录拆开了，视觉还绑在键盘上。

采用

顶栏四叶 + 全宽表单 + 按需小预览

配置页长相；灯效 / 迷你栏旁嵌细条或灯点，数据页可关掉预览。

1. 任务不同

虚拟键盘 =「这颗键绑什么」。Agent =「灯怎么亮、条上显示什么、何时出现」。前者需要键盘画布，后者需要表单。

2. 目录要可辨

左栏拆出 Agent，就是为了离开 Soft Pad。若壳一模一样，用户会以为点错了，或继续在两处找灯效。

3. 预览按页给

灯效要灯点、迷你栏要细条、样式要皮肤感——用右侧小预览够了。数据页关掉预览，不浪费宽度。

对齐市面

Stream Deck：主画布绑键；亮度等进 Preferences 表单页，不是再开一块半屏键帽。

对齐本产品

按键 / 语音 / 摄像头是动作面各有形态；托盘等配置页是表单。Agent 归配置组，跟托盘一类，不跟虚拟键盘一类。

实现边界

Soft Pad：keys + 左预览。Agent：lights|data|style|mini 顶栏；小预览组件按子页显隐。
