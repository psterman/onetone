# 首页 · 小白通道卡 设计方案

> 原型文件：`home-beginner-channel-shell.html`
> 目标用户：写作场景下的小白（首次配置 OneTone + Cursor）

---

## 1. 设计目标

- **零文字分类标签**：5 维框架（能力/数值/按键/状态/标签）不显式出现，靠**图标+空间位置**隐式表达
- **键盘是主角**：5×5 虚拟键盘放左侧中心，常用键紫色高亮
- **右侧 tab 集中展示**：能力 / 键盘 / 状态 / 历史 4 个 tab 切换，详情聚焦不堆数据
- **左右高度基本对齐**：顶部对齐（hero 区），底部右侧用"其他能力"/"其他键位"填充

## 3. 左侧：键盘为中心（综合组件）

### 3.1 三段视觉分层

| 段 | 主题色 | 元素 | 视觉特征 |
|---|---|---|---|
| 灯状态（top） | 绿色 (`--ok`) | 待命/待确认/已提交 | 当前态脉冲灯（`kbdLightPulse` 1.6s） |
| 详情键盘（mid） | 深色 + 紫色 | 5×5 键盘 + 3 个 feature 键 | feature 键紫色高亮 + 阴影 |
| 数值（bottom） | 紫色 (`--pad`) | 账号/额度/凭据 | 静态指示点，无脉冲 |

### 3.2 虚拟键盘

- 5 行 × 5 列 = 21 个物理键
- 单元格 36px 高（较原 28px 增大）
- 字号 8px（较原 7px 增大）
- Feature 键（高亮 3 个）：`ACT10`（开始说话）、`AG04`（发送）、`ACT08`（拒绝）
- 选中态：紫色描边 + 放大 1.04
- 按下态：紫色光晕动画

### 3.3 隐藏的高级项（不在初版展示）

| 隐藏项 | 理由 |
|---|---|
| 绑定（bind） | 默认已配置，无需每次操作 |
| 方案（scheme） | Pro 默认 |
| 状态灯配置 | 跟随前台 Agent |
| 总开关（ENC） | 默认开启 |
| 凭据（Token） | 已配置 |
| AG00/AG01/AG02/AG03/AG05 | 进阶快捷键 |
| ACT06/ACT07/ACT09/ACT12 | 进阶命令键 |

**显式展示的 8 个 item**：3 状态 + 3 常用键 + 2 数值

## 4. 右侧：4 tab 详情面板

### 4.1 Tab 列表

| Tab | 默认内容 | 选中 item 后内容 |
|---|---|---|
| **能力** | 5 个能力卡片（账号/方案/状态灯/Token/额度） | 详情卡 + 其他 4 个能力列表 |
| **键盘** | 21 键位列表（hot 键高亮） | 详情卡（功能+说明）+ 全键列表 |
| **状态** | 4 张状态卡：当前场景/Agent 状态/信号灯/前台应用 | 同左（无内层选择） |
| **历史** | 4 张历史卡：本月/本周用量 + 今/昨日活动 | 同左（无内层选择） |

### 4.2 详情页规范

- **只显示选中项的 3-4 行简介**（不堆数据）
- 结构：标题 + 状态值 + 2-3 行 fact（功能/逻辑/数据/下一步）
- 小白视角文案，避免技术术语

### 4.3 智能 tab 切换（点击行为）

| 点击位置 | 自动切到 | 触发 |
|---|---|---|
| 左侧键盘的键 | → 键盘 tab | `node.classList.contains('micro-hw__key')` |
| 左侧状态条 | → 状态 tab | id in `['standby','confirm','done']` |
| 左侧数值条 | → 能力 tab | id in `SP_CAPABILITIES.data` |
| 右侧能力卡片 | （留在能力 tab） | 默认 |
| 右侧键盘列表项 | （留在键盘 tab） | 默认 |

## 6. 交互闭环

### 6.1 主要 flow

1. 用户进入首页 → 看到当前习惯（Cursor · 写作）
2. 左侧键盘中心显示 → 3 个常用键（开始说话/发送/拒绝）紫色高亮
3. 用户点键盘上 AG04 → 右侧自动切到"键盘"tab，显示 AG04 详情
4. 用户点左侧数值条"额度 68%" → 右侧自动切到"能力"tab，显示额度详情
5. 用户点右侧 tab 切换 → 内容切换，左侧键盘不变
6. 用户点底部频道卡（说话/按键/屏幕/摄像头）→ 切换模式，左侧重渲染

### 6.2 模式差异

| 模式 | 左侧 hero 形态 | 来源函数 |
|---|---|---|
| voice（说话） | 生产线型：开启/听写/发送 三节点 | `renderProdLinearNav` |
| keys（按键） | 生产线型：触发/输出 两节点 | `renderProdLinearNav` |
| softPad（屏幕） | **键盘为中心 + 状态/数值条** | `renderOutlineNav` |
| camera（摄像头） | 多模态层级：维度 + 场景 | `renderMultimodalNav` |
