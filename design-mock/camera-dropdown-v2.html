场景 3 onAway
离席触发 · 隐藏按键注入子组

离席时不允许发键（按 Esc / IME 激活）
onAway / onReturn 在 allowedActionsForBindKey 里已禁按键类。 离席时人已不在座位，不应触发按键注入，避免误操作。

验收标准 UI 视角

  • 3 组无重复：每个 Camera 触发块下拉的 option 集合 = (组 1 专用 ∩ bindKey 白名单) + (组 2 推荐 ∩ bindKey 白名单) + (组 3 全部 ∩ bindKey 白名单)，三组之间不出现同名 option
  • 触屏可见：选中 input.cancel 后，若 Key 已绑 Esc，select 下方 chip 必现（不依赖 hover）
  • onAway 禁按键：下拉里看不到 pressEsc / pressCtrlI；如用户在 Voice 习惯里改过 IME 激活键，重渲后 onAway 下拉仍干净
  • Pending 显式：input.send / agent.approve 的 option label 末尾 · ⚠需确认，hint chip 红色
  • pressCtrlI 动态：label 显示实际按键名（如"右 Alt"），无配置时降级为"（未配置）"并加红色 hint
  • 帮助行：选中后 select 下方出现 1-2 行小字解释（Layer 1 等价 / Camera-only / Pending）
  • Phase 3 deep link：帮助行末尾 "查看全部入口 →" 跳到 habitView=actions&actionId=xxx
  • 运行时回归：选 input.cancel / agent:cancel / pressEsc 三种写法，运行时行为一致（都走 route_semantic_action → input.cancel）
