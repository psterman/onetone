v2 错位 我之前做成了编辑器

mapping 大卡片 + meta 行 + 3 个并列按钮 —— 视觉上跟 settings drawer 的设置项长得太像。用户进首页看到的是「这是一个配置展示面板」，不是「这是一个可以立即用的工具」。

  • 把 mapping 配置当主角（那是 settings 该展示的）
  • 3 个并列按钮（换习惯/测一下/新建）权重相等，看不出哪个重要
  • meta 行（目标/引擎/麦）信息密度太高，用户第一眼看不懂
  • 没有「立即上手」的引导感

v3 修正 首页 = 上手入口

VSCode 欢迎页 / Bear / Figma / Spotify 那一派：进来第一眼看到的是一个**明确的行动**。mapping 配置进 settings，首页只回答两件事：「现在能用吗」+「怎么用」。

  • 唯一大 CTA「试试看能不能用」—— 14px 大按钮，立即行动
  • 状态徽章 1 行搞定（绿/黄/红/灰），不解释，看色就知道
  • 不展示 mapping 配置，只在 footer 一行小字说「Vosk · cn-light」
  • 次要动作退到文字按钮（+ 新建习惯 / 使用引导）
  • 习惯切换条作为 底部导航条，不是顶部卡片
  • 状态切换时 CTA 自己变化（IDLE=测试，LISTENING=说话中，DICTATING=松开结束，ERROR=重试）
