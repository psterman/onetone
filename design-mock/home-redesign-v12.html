v11 三栏 + 设备兼容

v11 是桌面应用 dashboard 范：左全局导航 + 中央主面板 + 右设备兼容/性能/不建议清单。信息架构全，但不是 vibecoding 用户的母语。

  • 右侧是设备兼容 + 性能评级（工程师视角）
  • 中央是按键速查列表 + 数据卡 + 历史（信息陈列）
  • 顶部是Dashboard 标题 + 图标按钮（传统应用）
  • 没有 ⌘K 搜索（vibecoding 用户的第一入口）
  • 没有 快速命令（Raycast 风格的工具启动）
  • 没有 未来 AI 扩展位

v12 Command Center · vibecoding 用户首选

v12 整合 v11 三栏 + 图 2 Command Center 中央内容 + AI 未来扩展位。中央是 Raycast 风格的 Command Center：⌘K 搜索 + 当前触发大卡 + 快速命令 + 当前习惯 + 最近语音。右侧是最近语音 + AI 建议动作 + 云端 AI 输入 BETA 入口。

  • ⌘K 搜索框：Raycast/Linear/Notion 风格，vibecoding 用户第一入口
  • 当前触发大卡：紫蓝渐变 + 80px 大图标 + 实时波形 + 双 CTA（测试发送 / 切换习惯）
  • 快速命令 6 圆形 chip：6 个 M3 多色 container，每个 ⌘ 快捷键（⌘N / ⌘T / ⌘L / ⌘E / ⌘V / ⌘R）
  • 当前习惯单卡：当前映射 + 触发表 + 发送方案 + 成功率 + 切换按钮
  • 最近语音 · 列表 + 播放按钮：可重发
  • 右侧 智能建议 4 条（优化麦克风 / 备份 / 检查更新 / 使用指南）
  • 云端 AI 输入 BETA 入口（紫蓝渐变，未来扩展）
