架构改动

  • 拆 tray_menu_init_json → 4 个 assemble_* 函数；顶层 JSON 变 {status, actions, context, system}
  • 前端用 Web Components：<tray-status-card> / <tray-action-grid> / <tray-nav-row>
  • tray-mic-poll 改为事件驱动 + 60s 心跳；patch 只发变更 segment
  • 新增 tray_events 模块 publish 状态变化（mic_changed / scheme_changed）
tray_events::publish(MicChanged) → tray::refresh_segment("mic") → menu_win.eval("__tray_patch_seg__('mic',{...})") → <tray-status-card>.mic = {...}
推荐场景：多 IDE 多 Agent 切换频繁的重度用户；
刚装看的"产品感"最强。改动量：中。
