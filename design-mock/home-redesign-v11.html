v10 单栏 dashboard · 缺右侧帮助

v10 单栏布局，顶部 TopAppBar + 底部 NavigationBar。但缺一个关键东西：右侧上下文帮助。Codex 那个「选择按键方式」页面做对了：右侧一直显示设备兼容性 + 性能评级 + 不建议清单，让用户随时知道自己的硬件和方案能不能用。

  • 只有顶部导航，没有左侧全局 sidebar
  • 没有右侧上下文帮助 —— 用户切换习惯时不知道会不会卡
  • 没有设备兼容性参考 —— 不知道我的鼠标能不能用
  • 没有性能评级 —— 不知道当前方案快不快
  • 没有不建议使用清单 —— 不知道哪些键不该用

v11 三栏布局 + Codex 风

v11 把 Codex 的设计语言用到了主面板：① 左侧 sidebar 全局导航（7 个分类 + 底部状态卡）；② 中央主区（v10 的 Hero/Quick Settings/按键速查/数据卡/历史 全部保留）；③ 右侧 sidebar 三个 help-block（设备兼容性 + 性能评级 + 不建议使用清单）。

  • 左侧 sidebar：7 个 nav-item（首页/方案管理/触发设置/语音输入/声音与反馈/通用设置/运行状态/查看日志），active 时 4dp primary 指示条 spring 弹入
  • 右侧 3 个 help-block：① 设备兼容性（5 类硬件 ✓/⚠/✗）+ ② 性能评级（4 项数据：响应/准确/唤醒/发送延迟）+ ③ 不建议使用清单（4 项 negative guidance）
  • 中央主区保留 v10：Hero + Quick Settings 2x2 + 按键速查 list + 数据卡 + 历史
  • 底部状态卡：左侧 sidebar 底部显示「OneTone 已启动 · 语音服务 · 正常」
  • 所有状态切换（OK/LIVE/ERR）联动到中央 + 右侧
  • Spring easing：4dp active 指示条 + 图标 hover 弹性缩放
