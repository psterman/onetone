Notion 的形 · 我借什么

  • 暖米白底 #F7F6F3 —— 不是纯白，文档感的关键
  • 极简文本色 #37352F —— 比纯黑柔，墨水感
  • 几乎不用圆角 —— 4-6px 最大，硬朗但温和
  • 左侧栏 + 主内容 —— Notion 标准布局，语音笔记场景直接套
  • 图标单色 —— 不用彩色 emoji 风格，黑色细线条
  • 文档式封面 + 标题区 —— 给"语音笔记"赋予"文档"的产品感
  • Checklist 复用 —— 把"已识别词条"做成 checkbox，用户看到 ✓ 有完成感
关键：品牌蓝只在 live-callout 的麦克风图标和光标出现，整页不超过 3 处蓝色。Notion 的克制是核心气质，蓝色泛滥就废了。

Cursor 的形 · 我借什么

  • 深黑底 #1E1E1E —— 不是纯黑，编辑器质感的关键
  • Tab 标签栏 —— 把"语音笔记"做成多 Tab 编辑器，符合开发者心智
  • 代码语法高亮 —— 用 VS Code 配色（紫关键字 / 黄函数 / 橙字符串 / 蓝变量）
  • 底部 AI Composer —— 借鉴 Cursor 的 Cmd+K 输入框，做成"语音输入栏"漂浮在底部
  • 渐变光晕球 —— 麦克风图标用渐变蓝 + 光晕，替代 Cursor 的紫色 AI 球
  • 左侧 48px Activity 栏 —— VS Code 标志性极窄边栏，放核心功能图标
  • 代码高亮联动 —— 用户说"theme 是 cursor"，第 6 行立即高亮，语音输入直接改代码
关键差异化：Cursor 的紫色 #8B5CF6 全部替换为品牌蓝 #00A3FF，但保留 渐变光晕 和 球体呼吸动效。这种"用自家颜色做对方语言"的做法，能让用户感觉 voice-pilot 是"Cursor 生态里的语音插件"，而不是"又一个模仿 Cursor 的产品"。

→ vibe: 命令面板 · 中性专业 		原版用 red，改用 品牌蓝（光晕版）
Notion Notion 的暖米白 #F7F6F3 + 墨水文字 #37352F + 极简圆角 + 文档式布局
→ vibe: 文档笔记 · 内容创作者 		原版几乎无强调色， 仅在 live-callout 用品牌蓝（克制）
Cursor Cursor / VS Code 的深黑 #1E1E1E + Tab 编辑器 + 语法高亮 + 底部 AI Composer + 渐变光晕球
