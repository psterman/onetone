改动清单 · 给开发

CSS / Tailwind 直接抄 · Tauri 上零成本切换

背景 · 永远是 F2F2F7

所有页面外层背景换成 iOS 系统灰，卡片是白色浮在它上面。不要用纯白当背景，否则卡片浮不起来。

#FFFFFF→#F2F2F7

卡片 · 阴影代替边框

不要 1px 灰边线。改成 0 边线 + 极淡阴影浮起（0 4px 16px -6px rgba(0,0,0,.08)），iOS 17 风格。

border: 1px #E5E7EB→shadow + 0 border

圆角 · 14px 不是 8px

所有卡片 / 大按钮 / 大输入框统一 14px。chip / 标签 / 头像保持 999px pill。0 方角出现在主界面。

border-radius: 8px→border-radius: 14px

主色 · 007AFF 只用一次

系统蓝是强调色，不是主题色。一屏里最多 1 处大面积使用（主按钮 / 当前选中），其他全部灰阶 + 蓝字点缀。

#2563EB · 满屏→#007AFF · 主操作

分割 · Hairline 不抢戏

分组用 0.5px 半透明线（rgba(60,60,67,.12)），再小的信息差直接靠留白。绝不用 1px 实线灰。

border: 1px #E5E7EB→.5px rgba(60,60,67,.12)

字体 · 系统字体 + 字重

用 SF Pro / 系统字体栈，标题 600，正文 400。中文标题字号不要超过 20px，否则会"沉"。

Inter 700 32px→SF Pro 600 20px

按下反馈 · 透明 + 缩放

全局按钮加 :active { opacity: .7; transform: scale(.98); }，iOS 触感立刻有。不要 hover 变色。

hover: bg change→active: opacity + scale

图标 · 1.5px 描边单色

列表左侧图标用单色灰底（白图标 + 彩色 30px 圆角方块），颜色取自 iOS 系统色（蓝/绿/橙/紫）。不要描边 + 彩色混搭。

彩色描边 1px→单色 1.5px / 灰底白图
