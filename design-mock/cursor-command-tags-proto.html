分类标签 · 小白怎么选 Cursor 命令

先选来源，再选人话标签。每条命令都标清：是用 OneTone 操控 Agent，还是按下 Cursor 自己原来的快捷键——两套不要混在一个列表里假装一样。

A · Agent 操控

OneTone 替你在 Cursor 里完成「这一轮 vibe」：开麦、发送、停、新局、切 Plan/Agent、继续（口令）、接受改动。

对接：焦点 / OneTone 听写 / Composer 模式热键 / 塞话 / 接受 diff

B · 应用自带键

Cursor / VS Code 本来就有的和弦：搜文件、命令面板、行内编辑、前进后退……按下等于你在 Cursor 里手按同一组键。

对接：稳定 App 快捷键（软件自带目录）
选命令绑到 Soft Pad / 习惯 标签 = 小白话 · 来源 = 会不会和原快捷键搞混

小白默认只看 Agent 操控 →「这一轮」：开麦、发送、停、新局（+ 聚焦）。「继续」在口头指令通道，不进 Soft Pad 一键塞话。Plan/Agent、审改动第二周再露。「应用自带键」整栏对小白默认折叠进「更多」。

本页是分类共识原型，不改产品代码。落地时 Soft Pad「屏幕按钮」主推 A；Keys「软件自带」主推 B。重叠项（如发送 Enter）在 A/B 各出现一次时，文案必须带来源 pill。
