四叶解耦不够：按「改哪一层」重切成三层

截图里的 迷你栏 · 灯效 · 样式 · 数据 名字像四块，实际在抢同一块屏幕：条上有什么、何时出现、读数显不显。下面先拆耦合，再定新目录。

旧四叶 边界糊

迷你栏灯效样式数据

对照现在产品里 Agent + 样式页的真实内容：

用户想改的事 迷你栏 灯效 样式 数据
浮窗何时出现 形态里也有 — 何时出现 —
条上显示额度 用量开关 — — 预览摘要
忙闲怎么表示 圆点 键灯/氛围 — —
皮肤 / 细条样子 浮窗形态 — 外观皮肤 —
Hook / API Key — 塞在灯效匹配 — 额度来源

根因：四叶是按旧面板名字拼的，不是按运行时对象切的。迷你栏≈浮层 UI，样式≈浮层出现与皮，数据≈浮层上的数——三者本是同一层。

现在 Agent / 样式页 · 内容归位

现状入口真实在管问题
Agent · 灯效匹配接入 + 氛围灯 + 按键灯接入和灯绑死；和样式·灯效重复
Agent · 显示数据读数 + 条上摘要开关 + 来源「摘要开关」属于浮层，不该独立成叶
Agent · 迷你栏条内容 + 形态 + 何时浮出与样式抢「何时 / 长什么样」
样式 · 何时出现显示方式 + 皮肤 + 聆听口令名叫样式，却管生命周期
样式 · 动作键AG / 数字键映射属绑键，应回虚拟键盘
样式 · 灯效 / 迷你栏与 Agent 同渲染器双入口，解耦为零

按运行时三层切 推荐

一层一个对象，叶子之间尽量零重叠。

Layer · Overlay

浮窗

  • 何时出现（唯一）
  • 皮肤
  • 细条 / 完整键盘
  • 条上：忙闲 · 话术 · 快捷 · 读数显隐
  • 聆听口令
← 样式·何时出现 + 迷你栏 + 数据·摘要开关
Layer · Pad signal

灯效

  • 氛围灯（盘边）
  • 按键灯（模板/色）
  • 只谈「键上怎么亮」
← Agent/样式 双边灯效（去重）
Layer · Plumbing

接入

  • 虚拟键盘开关
  • Hook / 连接
  • 额度 API / 本地统计来源
← 灯效匹配·接入 + 数据·来源
丢掉的叶

不再单开「样式」「数据」「迷你栏」三个名字——它们描述的是同一浮层的不同侧面。动作键不进 Agent，留在虚拟键盘顶条。
