后期 · Vibecoding

灯效如何对长时间挂机写码有用
  1. 流式忙态 — running 时 AG 键微脉冲，一眼知道 Agent 还在干活。
  2. 等你打断 — needs_input 高对比，挂机回来不会漏提示。
  3. 皮肤成套 — vibe-light / vibe-dark 与状态预设绑定，少调参。
  4. 不默认轰炸 — 核心三 Agent 仍默认关灯，接通后再建议开启。

本原型仅展示文案位；不实现上述行为。
