快捷入口

v7 错位 是 Material 的"皮"

学了 M3 的大圆角、彩色图标、微动效 —— 但内核是错的：每个 section 一种语义色（青/绿/紫），每个按钮一种色（橙/粉/紫/青绿/绿）。这是"彩虹 UI"，反 M3 的 Color Roles 原则。

  • 每个 section 头部不同色图标块—— M3 不这样
  • 6 个快捷按钮6 种语义色—— M3 用 primary + secondary + tertiary 三色
  • 用 box-shadow 模拟 elevation—— M3 用 tonal elevation（surface color tonal 叠加）
  • hover 用背景变色—— M3 用 state layer overlay（8%/12%/16% primary）
  • 字体大小混乱（13/14/15/22/32 都有）—— M3 用 type scale（headline/title/body/label 五级）
  • 圆角全部 rounded-2xl—— M3 shape 分七类，按组件用途选
  • 所有 section 头部用彩色图标块—— M3 用纯文字 titleLarge 22px

v8 Material 3 的"骨" — 全部贯彻

v8 真正按 M3 规范重做：25 个 Color Roles（primary/secondary/tertiary + container/on）+ Tonal Elevation 5 层 surface + State Layer 8%/12%/16% overlay + M3 Type Scale + Shape 七类 + Emphasized easing。

  • 25 个 CSS 变量对应 M3 Color Roles（--md-primary / --md-on-primary / --md-primary-container / --md-on-primary-container 等）
  • 5 层 surface tonal（lowest/low/container/high/highest）—— 不用 shadow，靠 tonal 叠加
  • Hero Card (Filled tonal)：primaryContainer 背景 + onPrimaryContainer 文字 + 64px 图标 + Filled + Tonal 双按钮
  • State Layer：所有可交互元素用 ::before 叠加 primary 8%/12% overlay，不改背景
  • List Card (M3 ListItem)：单张 surfaceContainer 卡片包含多行，items 之间 1px outline-variant divider
  • Icon Buttons：48px rounded-md icon container + secondaryContainer 背景 + 下方 13/500 标签
  • M3 Type Scale：titleLarge 22 / titleMedium 16 / bodyMedium 14 / labelLarge 14-medium / labelMedium 12-medium 等
  • Emphasized easing：cubic-bezier(0.2, 0, 0, 1) 而不是 (.2,.8,.2,1)
  • TopAppBar 64px：center-aligned title + leading/middle/trailing 三段
  • Section header：纯 titleLarge 文字（不再用彩色图标块当锚）
