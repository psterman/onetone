架构与决策

3 个原型**功能完全一致**，只有 3 个元素的位置不同。生产实现里这是 1 套代码 + 3 个 layout class（.p1-body / .p2-body / .p3-body）。 选哪个根据：窗口大小、用户首选分辨率、是否要兼顾窄屏。

数据契约（3 个原型共享）

① 托盘预览
preview: TrayState
  .{ global, mic, channels[], event }
// 来自 V5 改造后的状态模型
② 4 通道
channels: Channel[4]
  .{ id, enabled, state, meta }
// 点开关 = 切 enabled,
// 立即改 TrayState 然后回灌
③ 即时数据
live: {
  mic_level: u8,
  current_app: string,
  habit: string,
  last_event: LastEvent
}
// 1s 节流推送

3 个原型的取舍

维度 P1 控制塔 P2 驾驶舱 ⭐ 推荐 P3 全屏预览
扫视路径 左→中→右（3 跳） 左 / 右上 / 右下（2 跳） 上→中→下（3 跳）
tray 视觉占比 ~45% ~38% ~58%
4 通道物理感 最强（独占一列） 强（2×2 网格） 中（横条压缩）
窄屏适配 差（170px 列卡） 中 差（高度 ≥ 700px）
vibecoder 5 秒可用？ ✅ ✅✅ ✅
