问题：中心被围攻、元数据外溢、按钮喧宾夺主、整体像配置面板而不是语音插件。

建议 改造后 · mockup

140px 中心 orb + 30px 大字提示 + 1 主 1 辅按钮 + 角落 11px 小字元数据。Header 缩到 2 个动作。底部习惯一条线。

关键变化：
  • orb 尺寸 64 → 140px，去掉外扩光圈动画，改为柔和呼吸
  • 主提示字号 14 → 30px，kbd 改为真正的 macOS 风键帽样式
  • 可见按钮 4 → 3（1 主 + 1 测试 + 1 ···），情景模式 / 设置 / 习惯切换收进菜单
  • 三 pill 状态 → 1 行 11px 小字 + ·· 分隔，仅在 hero 底部一行
  • Header 状态条 32px → 顶部居中胶囊（待命 / 唤醒 / 听写 三态切换）
  • 底部习惯 3 横滑卡片 → 一行标签 + 切换器，像 Notion 工作区
  • 背景 浅灰 + radial → 近纯白 + 极淡 radial，中心浮起来
