对照 Codex Micro · 重思 Cursor Soft Pad

Codex Micro Soft Pad 的本质是：小键盘上的少数一键动作（按一下就有可见结果），不是「Agent 能力操作系统」。Cursor 应继承拓扑与原则，把场景目录收成「本轮循环 + 模式列 + 更多」，而不是 7 轨 × 19 槽的 IDE 遥控器。

重思结论：保留 AG/ACT 物理分区与「一键生效 / 禁止塞话」；砍掉默认首屏里的导航·工具·浏览器；Plan/Agent 明确标成 Cursor「模式列」（+/·）；粘贴发送标成多步工作流；继续/跑测试仍走口头指令。屏幕按钮 ≠ 软件自带。

Codex Micro 原原则应继承
  • 一键生效按一下 → 眼前立刻变（开菜单 / 新对话 / 发送 / 停 / 开麦 / 聚焦）
  • 对齐官方能力尽量是 App 已有快捷键或焦点，不发明第二套 CLI
  • 禁止 insertOnly 塞话Soft Pad 不灌 /plan、不自动 Enter 发 slash
  • 扁平小白名单openEditKeycap ≈ 二十个以内「能记住」的动作，不是场景浏览器
  • 灯 ≠ 键状态灯可挂在 AG00，按下仍是命令菜单
当前 Cursor Soft Pad 偏离要纠偏
  • 7 场景轨 × 19 槽变成能力目录 OS，违背「少数一键」记忆模型
  • 导航 / 设置 / 浏览器进首屏IDE 遥控器，不是 vibe 循环
  • 常用里塞 plan需求文档初学者环是：说→发→（继续走口令）→新局；Plan 属第二周
  • pasteAndSend 与 Enter 平级实为 focus→粘贴→发送多步，诚实边界被抹平
  • 与 Keys「软件自带」并行易混channel 都叫目录，用户不知道绑键帽还是加识别键

Cursor 在同一拓扑上怎么放分化和弦，不分化分区
  • 同一肌肉记忆7–9 / 4–6 / 0 / Enter / ENC 语义与 Codex 同族；只换 Cursor 和弦（Ctrl+I、RAlt、Ctrl+Shift+Backspace…）
