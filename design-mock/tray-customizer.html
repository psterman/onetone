虚拟键盘 · 第 3 hero 重构 · 托盘菜单定制器

把"项目时间胶囊"换成"托盘菜单定制"，解决两个问题：① 时间胶囊和别的"项目"心智离得远，在虚拟键盘页不聚集 ② vibecoder 用户缺一个"把托盘调成自己顺手的样子"的可视化入口。 下面分 4 块：行业参照 → 与习惯的边界 → 定制器页面原型 → 数据模型与实施。

① 行业案例 · 借鉴什么

不照搬，挑出对"小面板 + 实时预览"这种场景最有效的 5 个模式。

VS Code Settings Form + JSON
Form/JSON 双视图双向绑定，初学者用表单，Pro 直接改 JSON。我们 1:1 抄：默认 Visual Tab，Pro 切 JSON Tab。
Raycast Preset + Live Preview
内置 preset 一键切换 + 改动立即反映到命令面板。我们给 4 个内置 preset（默认/极简/力量/演示），每个 preset 切换后托盘立即变样。
Apple 控制中心 Edit Mode
长按进入编辑模式，可增删/排序控件。我们不做"增控件"（section 数量固定），只做"显示/隐藏 + 顺序"——拖动 section 头部即可重排。
Figma Variables Token 引用
样式不硬编码，全部走 design token。我们 1:1 抄：托盘所有颜色/圆角/字号都是 CSS var，定制器改的是 var 赋值，不动结构。
Linear 后台保存
设置改动不打断当前工作流。定制器改动保存到磁盘，下次打开托盘才生效，避免用户在编码时被弹窗抢焦点。
Stream Deck 网格编辑
每格 1 动作的网格化编辑。不取——我们的 section 数量固定（5 段），网格化反而冗余。

② 与习惯的边界 · 不重叠在哪

定制器和习惯是两个正交面：习惯管"什么时候用什么 voice/keys"（行为 / when+which），定制器管"托盘长什么样、显示什么"（呈现 / what+how）。下表给个判定表。

用户问题归谁管落在哪
我在 VS Code 里按 F1 应该用什么 voice 命令？习惯 schemes习惯配置 / 自动匹配规则
我录的按键 HID_R03 80 怎么改成"按住说话"？习惯 schemes按键配置 / 触发方式
托盘里要不要显示"摄像头通道"这一行？定制器Content → Channel rows → camera ☑
托盘字号太小看不清怎么办？定制器Style → Density → Compact / Cozy
托盘打开时第一眼想看"现在能用吗"还是"刚才那句有没有发出去"？定制器Content → 显示顺序（拖动 section 头）
当 trigger 失败时托盘要不要高亮？定制器Effects → Outcome chip 颜色
某个 channel 我从来不用，能不能完全关掉？习惯 schemes习惯配置（关掉这个 channel 在该习惯里的启用）
托盘的"暂停"按钮我能不能隐藏？不能核心安全项，所有定制器都不能 disable

④ 4 个内置预设

用户切到 Presets Tab 能看到。每个预设就是一份命名的 TrayCustomization。

默认 Default 当前
V5 完整版：状态+事件+4通道+麦+深链。适合大多数 vibecoder。
极简 Minimal
只显示 Hero 状态 + 麦静音。屏幕小、临时会议时用。
力量 Power-User
完整 + 引擎健康 + 事件历史 5 条。调试 / 排查问题时用。
演示 Demo
大字号、高对比度，演示 / 录视频时用。强制浅色 + 圆角放大。

⑤ 数据模型 + 与 V5 托盘的集成

Rust 端独立 struct，TS 端 specta 生成；托盘 CSS 全部走 var，定制器只赋值不动结构。

Rust · tray_customization.rs
// 与 V5 tray_state.rs 同目录 #[derive(Serialize, Deserialize, Clone, Debug)] #[serde(rename_all = "camelCase")] pub struct TrayCustomization { pub version: u32, // schema version pub active_preset: Option<String>, // "default"/"minimal"/"power"/"demo"/用户自定义 pub style: StyleConfig, pub content: ContentConfig, pub effects: EffectsConfig, pub capabilities: CapabilitiesConfig, } pub struct StyleConfig { pub theme: String, // "auto"|"light"|"dark" pub accent: String, // "cyan"|"purple"|"green"|"orange"|"red"|"slate"|"custom" pub accent_hex: Option<String>, // 当 accent=custom 时 pub density: String, // "compact"|"cozy" pub icon_set: String, // "outline"|"filled"|"minimal" } pub struct ContentConfig { pub visible_sections: Vec<String>, // ["hero","event","channels","mic","footer"] 拖动排序 pub visible_channels: Vec<String>, // ["voice","keys","softPad","camera"] pub visible_deep_links: Vec<String>,// ["main","settings","diagnostic"] } pub struct EffectsConfig { pub pulse_animation: bool, pub outcome_chip: bool, pub sound_on_toggle: bool, pub event_auto_collapse: String, // "never"|"5s"|"15s"|"on_next" } pub struct CapabilitiesConfig { pub global_pause_button: bool, // 默认 true，UI 不让关 pub deep_link_chevron: bool, pub channel_state_display: bool, pub event_history_size: u8, // 0=关, 1=最近1条, 5=5条 } // 加载与持久化 pub fn load() -> TrayCustomization // 从 data_dir/tray_customization.json 读 pub fn save(cfg: &TrayCustomization) // 写回 // 应用到托盘 CSS pub fn render_css_vars(c: &TrayCustomization) -> String { // 返回 "--tray-accent: #2a9cc4; --tray-density: 0.85; ..." } // 4 个内置 preset pub const PRESETS: &[(&str, TrayCustomization)] = &[ ("default", ...), ("minimal", ...), ("power", ...), ("demo", ...), ];
TS · tray-customization.ts (specta 生成)
// specta 自动从 Rust 生成 export interface TrayCustomization { version: number; activePreset: string | null; style: { theme: 'auto' | 'light' | 'dark'; accent: 'cyan' | 'purple' | 'green' | 'orange' | 'red' | 'slate' | 'custom'; accentHex?: string; density: 'compact' | 'cozy'; iconSet: 'outline' | 'filled' | 'minimal'; }; content: { visibleSections: string[]; visibleChannels: string[]; visibleDeepLinks: string[]; }; effects: { pulseAnimation: boolean; outcomeChip: boolean; soundOnToggle: boolean; eventAutoCollapse: 'never' | '5s' | '15s' | 'on_next'; }; capabilities: { globalPauseButton: boolean; // UI 锁住不让关 deepLinkChevron: boolean; channelStateDisplay: boolean; eventHistorySize: number; // 0/1/5 }; } // 渲染：把 customization 注入到 tray 根元素 function applyCustomization( trayEl: HTMLElement, c: TrayCustomization ) { trayEl.style.setProperty('--tray-accent', accentColor(c)); trayEl.style.setProperty('--tray-accent-deep', accentDeep(c)); trayEl.style.setProperty('--tray-accent-soft', accentSoft(c)); trayEl.style.setProperty('--tray-density', densityValue(c)); trayEl.dataset.hideEvent = String(!c.content.visibleSections.includes('event')); trayEl.dataset.hideMic = String(!c.content.visibleSections.includes('mic')); trayEl.dataset.hideChannels = String(!c.content.visibleSections.includes('channels')); trayEl.dataset.theme = c.style.theme; // 节流写入避免拖动时 jank }
