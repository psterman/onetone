多选任一触发即 Esc：① 再按启动键窗 cancelEnabled+intervalMs；② 取消词 voiceEnd.cancelPhrases*；③ 摄像头手势 → pressEsc。现网入口分散在 Keys / 语音页 / 摄像头偏好。

voice_end_runtime · camera-presence-actions

F

触发键 + 触发方式

triggerKey + triggerMode(tap/double/hold)。hold → finish 只剩 perpress；与 E 耦合。

keys-panel-ui · trigger

整理时常见纠缠点
  • C 写 targetKey 与 D 录制互相覆盖，谁是 source of truth？
  • E 的可选模式依赖 F 的 gesture，但 UI 分属两步
  • B 的「输入法」把「选 IME」和「配 finish」捆在同一右栏
  • 自定义键时 E 仍挂在 keysCaptureKeyPanel，与 IME 共用宿主
  • 取消三通道现网分散；产品落地时需在 Keys「取消听写」收口，勿再只藏 details
