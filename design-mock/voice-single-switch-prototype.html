语音单开关 · 按需听写（修订原型）

第一性原理结论：用户只决定「语音开/关」；默认不常驻监听；听写是会话反馈，不是第三种可选模式。取代 voice-phase-3state-prototype.html。

design-mock/voice-single-switch-prototype.html

废弃：三态 pill · 暂停按钮 · 关闭/暂停双轨

旧方案（过繁）

  • 用户要理解：关闭 / 待机 / 听写 / 暂停
  • 首页 3 个按钮：开启 · 暂停 · 关闭
  • 默认 auto 常驻 KWS/Vosk → 内存 + 误触
  • 「待机」不是用户需求，是实现层

新方案（单开关）

  • 用户只操作：语音开 / 关
  • 听写 = 自动反馈（绿条 + 字幕），不用选
  • 默认 off，按按键才听写
  • 口令唤醒 = 设置里显式 opt-in

用户心智公式

内部可以有很多状态机，首页只回答一个问题：「我现在能不能用语音输入？」

一个开关 · 一行怎么说 · 听写时多一行反馈

按 {key} 或说口令 → 触发 听写中
