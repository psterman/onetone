现在 你的截图 · 现状

首页当成了输入面板 —— 中心一个 64px 小球被三个 pill + 四个并列按钮围攻，权重被稀释。用户 99% 的语音输入根本不通过这个按钮（物理按键和 HUD 才负责），所以它既不是核心信息，也不是高频动作。

  • Header 4 个等权按钮（当前窗口/总开关/情景模式/设置），没有主次
  • 顶部 32px 三段状态条（引擎/延迟/字符数）—— 信息密度相同，没有层级
  • 64px orb 配三个状态 pill——视觉权重被围攻
  • 4 个并列按钮（结束说话/选择按键方式/切换目标/语音设置）—— 喧宾夺主
  • 3 个横滑习惯卡片——和 hero 各自为政，没层级
  • 没有「+ 新建」明确入口，藏在「我的习惯」按钮后面
  • 用户真正高频的：换习惯 / 测试发送 / 看 HUD 开关，都被埋没

建议 改造后 · 仪表盘定位

首页的角色明确为「mapping 状态仪表盘 + 入口」—— 5 秒看一眼就知道现在什么状态、要不要换。语音输入的中心在 HUD（屏幕底栏气泡），不在这里。

  • Header 缩到 2 按钮（设置 + ···），总开关/情景模式/HUD 全部进菜单
  • 删 32px 顶部状态条，元数据沉到 hero meta 一行小字（11.5px 灰字）
  • 中心 = 1 个 mapping 大卡片（触发键 → 目标键 + IME → 触发模式/结束/唤醒/目标），用户每次打开要确认的核心
  • 底部 habit 横排标签，像 Notion 工作区，含「+ 新建」直接进 habit_setup overlay
  • 可见动作 = 2 个：「换习惯」+ 「测一下」（加可选「+ 新建」）—— 其他都进 ··· 菜单
  • 4 态响应：IDLE 静默灰、LISTENING 蓝色发光、DICTATING 强脉冲、ERROR 红色
  • footer 一行细字：版本 / HUD 状态 / 自启 / 资源 —— 像 macOS 菜单栏辅助工具
  • 浅深主题切换（应用已有清澈/石墨两套）
