Config UX · direct manipulation

配置要「对着实物改」，不是对着开关列表猜

上一版只有表单行，看不出改的是条上哪一块。正确做法：中间是运行时会看到的东西，点哪里配哪里；右侧才是这一块的开关。

不直观（旧稿）

纯表单：显示额度 · 忙闲圆点 · …

用户不知道这些字对应屏幕上哪一截，只能死记文案。

直观（本原型）

点迷你栏上的「72%」→ 右侧出现额度开关

实物在中间，控件贴着热区。仍不做半屏绑键键盘。

正在配置

点左侧预览上的高亮部位

中间 = 你平时看见的

迷你栏页放细条浮层；灯效页放盘边/键灯；样式页放「出现方式」可视化卡片。不是设置专用的抽象列表。

点部位 = 打开对应控件

点忙闲点 → 管谁在忙；点 72% → 管额度显示；点快捷钮 → 多选按钮。文案跟着部位走。

仍不是 Soft Pad 壳

不占半屏数字键盘画布。预览只渲染「配置对象」本身；绑键继续去虚拟键盘页。

数据页怎么直观？

数据页复用迷你栏顶行：点「账号 / 额度 / 重置」每一段，右侧只出这一段的开关与来源。表单挂在实物上。

样式页怎么直观？

四种「何时出现」做成带小示意的卡片点选，不要四个干电台。皮肤用缩略条，点选即换。

和虚拟键盘的边界

这里改「亮什么、条上有什么、何时露」。改「键绑什么命令」仍在虚拟键盘左预览右列表。
