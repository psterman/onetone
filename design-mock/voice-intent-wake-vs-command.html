全局唤醒词只服务输入法；其余意图配命令词

「一声」这类词是开听写的全局唤醒。自定义快捷键 / 模板 / 口头命令 / 应用快捷键 / 软键盘 / 手势配的是命令词。命令词默认不常开监听——要另开一条「收听窗」。

（可选：声音样本走声学匹配，仍属命令，不是唤醒）
模板Prompt 命令词 / 短说法

应用快捷键App 命令词

禁止混用：不要把「一声」既当输入法唤醒、又当自定义快捷键的命令。唤醒开听写；命令执行动作。

路径 A · 开听写

全局唤醒
  1. 1

    设置里打开 全局唤醒（voiceWakeListeningOptIn）

  2. 2

    配置输入法意图的唤醒词，如「一声」

  3. 3

    后台听到唤醒词 → 只开输入法听写，不执行快捷键/模板

说「一声」→听写开→打字

路径 B · 收命令词

口头收听窗
  1. 1

    在「口头命令」录好口头触发键（侧键等）

  2. 2

    各意图为本方案挂上命令词（保存 / 发送 / 模板短说法…）

  3. 3

    按触发键 → 短时收听 → 喊命令词 → 执行动作

侧键→收听窗→「保存」→动作

为何不常开听命令：命令词多、易误触、更耗资源。用按键开窗，和「全局只听唤醒」拆开。

可选高级

声音样本（声学）≠ 第二套全局唤醒

录了才进匹配池，用来替代/增强某条命令或唤醒的声学指纹。文案上叫声音样本，不要写成「全局语音命令开关」。

落地规则

  1. 输入法左侧只展示 / 编辑全局唤醒词；流程：说唤醒 → 输入法。
  2. 自定义快捷键 · 模板 · 应用 · 软键盘 · 手势左侧展示本方案命令词；小字可写「前置唤醒仅用于听写，命令靠口头收听窗」。
  3. 口头命令左侧是触发键；页内是可喊白名单（说法）。
  4. 「如何激活全局语音接收命令」→ 答案是按口头触发键开收听窗，不是再开一套常听命令的全局开关。
  5. 运行时保持三分：唤醒词 / oralCommandScheme / 声学样本 — 不重拆架构。
