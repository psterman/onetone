# 摄像头 Pro 页面 Windows Hello 红外摄像头延伸功能方案

> **口径收紧（以落地为准）**  
> 两条链拆开：**RGB + MediaPipe 视觉主链** vs **Windows Hello 认证 / HumanPresenceSensor 系统增强链**。  
> Hello **不等于** Gaze / 多人 / IR 增强 / 多屏能力。多人 Privacy Alert/Guard 与 Visualizer / 健康助手走 RGB 主链（已接入 Pro 通用区）。  
> 三段探测分开展示：A RGB · B Hello 认证 · C HumanPresenceSensor。设备名匹配只作启发式。  
> 多屏 Pointer/Snap/Display = 实验室灰显；Virtual Presenter = 不承诺上线。  
> 详见收紧版规划与 `camera-pro-glance.js`。

## 一、背景分析

### 1.1 Glance 软件的完整功能清单

基于对 Glance by Mirametrix 的深度研究，以下是它的核心功能：

**隐私与安全类**
- **Presence Detection (存在检测)** - 检测用户是否在屏幕前
- **Privacy Guard (隐私卫士)** - 检测到他人靠近时自动模糊屏幕
- **Privacy Alert (隐私提醒)** - 当有人在你身后看屏幕时提醒你
- **离席自动锁定 / 回席自动解锁**

**多屏与窗口管理类**
- **Snap Window (窗口快移)** - 点击并按住标题栏，看哪个屏幕，窗口就自动移到那个屏幕
- **Smart Pointer (智能指针)** - 视线切换屏幕时，鼠标指针自动跟随到你看的屏幕
- **Smart Display (智能显示)** - 模糊你没在看的屏幕内容，保护隐私

**视频会议类**
- **Virtual Presenter (虚拟演讲者)** - 视线追踪让你看起来像在直视摄像头
- **Auto Mute (自动静音)** - 离开时自动静音视频会议
- **Mute Warning (静音提醒)** - 提醒你当前是否处于静音状态
- **Smart Player (智能播放器)** - 看视频时视线移开自动暂停，回来继续播放

**数字健康类**
- **Digital Wellness (数字健康)** - 用眼健康提醒
- **20-20-20 Rule (20-20-20 规则)** - 每20分钟看20英尺外20秒
- **Posture Warning (坐姿提醒)** - 检测不良坐姿
- **智能眨眼提醒**

**辅助功能类**
- **Visualizer (视觉校准器)** - 实时显示你是否在最佳检测范围内（绿/黄/红）
- **Advanced Configuration (高级配置)** - 丰富的自定义选项

### 1.2 Windows Hello 红外摄像头的优势

- **不受光线影响** - 红外成像在各种光照条件下都稳定
- **活体检测** - 防照片、视频欺骗
- **深度感知** - 可以获取更精确的面部特征
- **Windows 原生支持** - 系统级认证能力

## 三、各功能板块详细设计

### 3.1 隐私保护板块（Glance 核心）

**隐私卫士 (Privacy Guard)**
- 触发条件：检测到第 2 张人脸、或人脸距离异常靠近
- 执行动作：屏幕立即模糊 + 可选声音提醒
- 灵敏度调节：可配置检测距离和人数阈值
- 白名单：可设置某些人脸（如同事）不触发

**智能显示 (Smart Display)**
- 多屏环境下，只保留你正在看的屏幕清晰
- 其他屏幕自动模糊或降低亮度
- 视线回到其他屏幕时，该屏幕恢复清晰
- 可配置模糊程度

### 3.2 多屏管理板块（效率神器）

**智能指针 (Smart Pointer)**
- 三种触发模式可选：
  - Instant (即时跟随)
  - CTRL 键触发
  - 摇晃鼠标触发
- 指针移动动画效果（可选）
- 可设置跟随延迟

**窗口快移 (Snap Window)**
- 操作方式：点击并按住窗口标题栏 → 看目标屏幕 → 窗口自动跳转
- 可配置：需要额外按键确认/直接移动
- 支持：窗口分屏位置预设（看屏幕左边自动靠左分屏）

### 3.3 视频会议板块（专业功能）

**虚拟演讲者 (Virtual Presenter)**
- 让你的视线看起来像在直视摄像头，建立连接感
- 支持多种模式：
  - 自然模式 - 允许一定视线移动
  - 专注模式 - 保持直视摄像头
  - 智能混合 - 阅读时允许向下看，其他时候保持注视

**会议自动静音**
- 离席检测 + 会议状态判断
- 自动静音/取消静音
- 可配置：仅静音麦克风 / 同时关闭摄像头
- 自定义延迟时间（避免短暂移动误触发）

### 3.4 健康助手板块（关怀功能）

**20-20-20 规则**
- 可自定义时间间隔（10-60 分钟可调）
- 多种提醒方式：
  - 温和弹出通知
  - 全屏遮罩休息提示
  - 自然风景展示（可选 Pro 内容）
- 可设置"忽略此提醒"次数限制

**坐姿与用眼**
- 坐姿偏离阈值时，温和提示"调整坐姿哦"
- 持续低头/仰头提醒
- 可设置提醒敏感度和频率

### 3.5 智能播放控制（休闲功能）

**智能播放器**
- 视线移开自动暂停（看手机、喝水等）
- 视线回来后 0.5-2 秒内继续播放（可配置）
- 可设置延迟（避免频繁暂停）
- 支持主流视频平台检测

### 4.2 关键技术点

```javascript
// Windows Hello 检测示意
const checkWindowsHello = async () => {
  // 通过 Tauri 调用 Windows API
  const result = await window.__TAURI__.invoke('check_windows_hello');
  return {
    available: result.isAvailable,
    cameraType: result.cameraType, // 'infrared' | 'standard'
    isConfigured: result.isConfigured
  };
};

// 视觉校准器状态
const updateVisualizer = (detection) => {
  let state = 'green'; // 最佳范围
  if (detection.distance > TOO_FAR || detection.distance < TOO_CLOSE) {
    state = 'yellow'; // 边缘范围
  }
  if (!detection.faceDetected) {
    state = 'red'; // 未检测到人脸
  }
  updateVisualizerUI(state);
};

// 隐私卫士检测
const checkPrivacyGuard = async (faces) => {
  if (faces.length > 1) {
    // 检测到多张人脸
    triggerPrivacyAlert('有人在旁边哦！');
    if (privacyGuardLevel === 'high') {
      blurScreen();
    }
  }
  // 检测异常近距离（从身后偷看）
  if (faces.some(f => f.distance < CLOSE_THRESHOLD)) {
    triggerPrivacyGuard();
  }
};

// 智能指针实现
const handleGazeScreenChange = (currentScreen) => {
  if (smartPointerEnabled && currentScreen !== lastScreen) {
    // 移动鼠标到目标屏幕中心
    moveMouseToScreenCenter(currentScreen);
    lastScreen = currentScreen;
  }
};

// 窗口快移实现
const handleSnapWindow = async (draggingWindow, gazeScreen) => {
  if (draggingWindow && gazeScreen !== currentScreen) {
    // 移动窗口到目标屏幕
    moveWindowToScreen(draggingWindow, gazeScreen);
  }
};
```
