Prototype · agentic loop

以 Loop 为圆心：主动搜网，直到把问题解完

不是「一次 search_code 就收工」，也不是「请点顶部工作」。圆心是持续运转的 goal → 选工具 → 观察 → 再行动；证据不够就主动 web_search / fetch_url，够了才 finish。

LOOP
Goal Act Observe Decide

一轮里模型自己决定下一步

  1. Goal：锁定用户要什么（不是填表推诿）
  2. Act：仓库不够 → web_search；摘要不够 → fetch_url；本地相关再 search_code
  3. Observe：看命中是否够回答；缺口写进下一圈
  4. Decide：证据够 → 自然语言结案；不够 → 继续 loop，禁止叫用户「去点 Tab」
