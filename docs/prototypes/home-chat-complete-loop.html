Prototype · LangChain / LangGraph

用 LangChain 方案补全：Agent + Tools + Memory + Graph

不引入 npm 依赖也能按 LangChain 心智落地：ChatModel.bind_tools → LangGraph（agent ⇄ tools，可 interrupt 到 human）→ MemorySaver(thread_id) 会话归属 → Callbacks 驱动 UI 步骤。 OneTone 映射：ModelGateway ≈ ChatModel，ATR/research/Soft Pad ≈ Tools， WorkController ≈ AgentExecutor/Graph，journal ≈ checkpointer。

LangGraph 节点（本轮高亮）

START → agent → tools ⇄ agent → human → deliver → agent → END / finish
条件边：should_continue — 有 tool_calls 去 tools；要澄清去 human； 要投递去 deliver；否则 END。禁止用「请点顶部工作」代替边。
