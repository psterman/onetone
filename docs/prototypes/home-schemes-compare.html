首页方案比较

针对装订台过载：首页要更简单、能力直达上手，又不能退化成「一个输入框 + 加号藏能力」。下面三份自包含 HTML 可点开对照。

共同约束： 保留左栏「现在 / Agent / 我的习惯 / 设置」；任意时刻最多一个高强调主 CTA；能力有名字、可见，不进「+」菜单；不做搜索引擎式单框；假数据原型，不接 IPC。

A · 情境驾驶舱 + 可见能力

最贴 PRODUCT

首屏回答「我在哪 / 下一步」。能力用三块具名入口（整理简报 / 听写 / Agent）始终露出——装订工作台不进首页。

适合

  • 坚持情境是主业
  • 希望首屏最安静
  • 简报/听写是「去某能力」

代价

  • 新工作要多点一次才进装订
  • quiet 时首屏偏「空」需靠能力区补存在感
打开方案 A

B · 一句话开场 + 可见材料条

上手最快

打开就能写「你的话」。材料用三个具名按钮（文本 / 文件 / 链接）直达，芯片只做开/关。情境压成顶栏一行。

适合

  • 高频「马上交代 Agent」
  • 讨厌四档引用表
  • 要直达、但仍看见能力

代价

  • 情境叙事变弱（顶栏）
  • 与「Prep 次级」略冲，需靠顶栏 CTA 守单按钮
打开方案 B

C · 两拍页：情境一行 + 轻装订

折中

第一拍情境标题行（需要时才出唯一主按钮）。第二拍轻装订：左投料右写话。无常用上下文架、无四档引用。

适合

  • 既要看见情境，又要当场开工
  • 从 brief-desk 减负后的方向

代价

  • 同屏两拍，仍比 A 噪
  • 窄屏会叠成上下两段
打开方案 C 对照：旧装订台
维度 A 驾驶舱 B 开场写话 C 两拍轻台
首屏主业 情境 + 下一步 写意图 情境一行 + 轻装订
能力如何露出 三块具名入口 三材料按钮 + 交接 投料类型芯片 + 交接
相对「单框+加号」 完全不同 有大输入，但能力外露 双栏，能力外露
相对旧 brief-desk 装订不进首页 去掉引用档位表 去掉上下文架与四档
贴 PRODUCT.md 最贴 偏弱 中等

刻意不做： 全页只留一个搜索/聊天输入框；把粘贴、文件、网址、听写、Agent 全塞进「+」；首屏铺开全文/摘要/引用/不发送矩阵。
