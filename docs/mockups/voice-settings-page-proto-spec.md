## 0. 定稿摘要

| 层 | 策略 |
|----|------|
| **架构** | 听写是语音主场；SoftPad / 按键 / 摄像头 = **有口令才在此改说法** 的桥面；跨应用拉起=高级默认关；**全局听写**（空 `appTargetId`）= 光标处听写 |
| **UI** | 四面（听写 \| SoftPad \| 按键 \| 摄像头）；听写两步（开启 \| 说完了）；落点一句旁注；试麦克风在 dock；通道试说在各桥面内 |
| **页面** | **废除**打开应用第二面与方案卡双铬；改目标回按键页；口令写回各自通道 |

## 1. 页面一句话

**语音设置 = 配置「听写」这条输入法环，并充当各通道口令枢纽；不是 Agent 总控台，也不是跨应用自动化中心。**

| 意图 | 用户在干嘛 | 谁负责 |
|------|------------|--------|
| 输入法操作 | 字进光标处 | **本页主职**（听写 01→02） |
| 改 SoftPad / 按键 / 摄像头说法 | 有口令才出现在桥面 | **本页桥面**；键位·手势·目标仍回通道页 |
| 定位 / 控 Agent | 发送、继续、新会话 | SoftPad / 迷你栏（点 = 说）；桥面可改说法 |
| 对电脑操作 | 开应用、切窗 | 习惯目标 + 按键；跨应用拉起仅高级 |

按键 vs 语音：**同一习惯动作的两种触发器**（按 vs 说）；语音独特主职只有 **听写**。

## 2. 运行时裁决

```text
情景可匹配命令  >  听写入口
听写中          →  只认收尾词
未听写 + 已 arm →  只认当前亮卡
前台优先        →  应用落点下已在目标应用则直接执行
跨应用拉起      →  高级选项，默认关（仅应用落点）
全局听写        →  字进当前光标；不做错前台拦截
```

| ID | 规则 |
|----|------|
| R1 | 不靠设置页「模式总开关」；靠语境 + 状态机 |
| R2 | 听写中 / arm 未听写：grammar **互斥** |
| R3 | **情景匹配优先**，再考虑纯听写唤醒 |
| R4 | 常用情景 = `activeSceneId`（与按键 / SoftPad 同一世界） |
| R5 | 粘性 = **只抗切换**；从不自动 `activateScene` |
| R6 | 记录有效执行供大总结；**不**自动提权口令 |
| R7 | 空 `appTargetId`（**全局听写**）：听写跟光标；Agent 口令仍按 R3（不因全局而关闭命令环） |

### 2.1 应用落点 · 错前台

| 用户说了 | 高级「允许拉起」 | 行为 |
|----------|------------------|------|
| 听写入口词 | **开** | 打开/聚焦目标 → **开始听写**；**不**自动发送 |
| 听写入口词 | **关**（默认） | **不执行**；状态行已提示；**仅此时** toast 一次 |
| 继续 / 发送 / 新会话 | 任意 | **不**进听写；「继续」最多 **只聚焦目标**，不自动执行 slot |
| 情景认不出 + 未 arm | — | 不执行 |

### 2.2 落点旁注（Q17–Q18 · Q41 · Q38）

数据分叉不变：当前习惯 **空** `appTargetId` ↔ **非空**。UI **禁止**再写「无目标」；**禁止**「全局听写 \| 应用情景」双卡竞选。

页内始终只有 **一句后果**（落点旁注），不是两套方案可选。对照：[voice-dictate-01-final.html](../../design-mock/voice-dictate-01-final.html)。

**与 [HABIT_UNIFIED_CONTRACT](../HABIT_UNIFIED_CONTRACT.md) 对应（Q38）：**

| 落点旁注 | 契约层 | 不是 |
|----------|--------|------|
| **跟光标**（空 `appTargetId`） | **§A 默认习惯**上的听写落点：字进光标 | **不是** §B 全局底座；引擎/麦 baseline 仍在 dock「引擎策略」 |
| **进 {name}**（非空） | 有 `appTargetId` 的习惯上的听写落点 + 错前台闸 | 不是另起一套「语音方案」名词；数据仍是 mapping |

对外「通用设置」可合并称呼 §A+§B；语音页落点旁注**只反射当前正在编辑习惯是否绑应用**，不编辑 §B。

| | **跟光标** | **进 {name}** |
|--|------------|---------------|
| 条件 | `appTargetId` 空 | 非空 |
| 文案 | 「字会打进**你正在点的地方**（跟光标走）」 | 「字会打进 **{name}**」 |
| 引导 CTA | 「要限定到某个应用更稳？去按键设一下 →」 | 「不对就去按键改目标 →」 |
| 承诺 | 字进当前光标；不做前台比对 | 前台优先；错前台可拦；高级可拉起 |
| 高级拉起 | **不出现** | 01「高级」折叠内（Q44）；默认关 |
| 错前台状态行 / toast | **不启用** | **两者都要**（Q15）：状态行常驻 + 说了才 toast |
| SoftPad「继续」等 | **仍有效**（R3 / Q18） | 同左；落点受目标约束 |

切换归属：**仅按键/习惯**改 `appTargetId`；语音页**不**放「全局 \| 应用」本地 toggle（避免双写）。落点 CTA → **按键页目标/情景编辑区**（Q32 精神保留）；语音内「按键」桥面只管口令，不编辑目标。

## 3. 架构策略（壳与通道）

### 3.1 语音设置在壳中的位置

- 左栏仍只有 **「语音设置」** → `voiceWake`  
- **不**新增左栏「打开应用」或「全局语音」通道  
- **Q39 / Q40**：页级面 = **四面**；`voiceFace` ∈ `{dictate, softpad, keys, camera}`  
- **废除** `voiceFace=openApp` 及打开应用 roster 第二面；开应用类若有口令，走按键/通道投影，不在语音单开一面  
- face 切换条 = **顶栏下方独立一行**；四面始终对称可见（听写步轨仅 `dictate`）  
- **默认**听写面；侧链/深链可指定三桥之一；**不**持久化「上次 face」  

### 3.2 与 SoftPad / 按键 / 摄像头

| 能力 | 归属 |
|------|------|
| 听写口令 / 说完了结果 | 语音听写 01–02 |
| 试麦克风（原本地试说） | 语音 **dock**，次要文字/ghost；**四面都显示**（Q21 · Q28′） |
| SoftPad / 按键 / 摄像头口令 | 对应 **桥面**：改说法、开关可说、面内试说；写回通道页（Q45） |
| 键位、手势标定、目标窗、全局↔应用 | 各通道页；桥面顶栏「去××页」；落点 CTA 聚焦按键页目标区 |
| 打开应用声学 | **不**占语音独立面；有口令则出现在按键桥（或通道投影） |

## 4. UI / 页面布局策略

### 4.1 壳层

```text
顶栏：语音方案 · 习惯 pill · 保存到正在编辑的习惯
页级面切换：听写 | SoftPad | 按键 | 摄像头
反馈轨（Q15 · Q25 · Q27′）：错前台状态行 —— face 下方、听写步轨上方；
  仅听写面；条件：应用落点 ∧ 不匹配 ∧ 高级关
事件 toast（Q15）：同上条件且用户说了听写入口词被拒时弹出 ~3s
缺模型：setup banner
听写面：两步轨 01 开启 | 02 说完了
桥面：SoftPad / 按键 / 摄像头口令（无听写步轨；无错前台状态行）
底栏 dock（四面同构）：麦 · 引擎策略 · 【试麦克风】（ghost）· 听到…
```

### 4.2 听写面 · 01 开启

```text
[01] 怎么开启打字？
  · Hero：默认口令（点大字改）+「不对就改」
  · 因果条：说出这句 → 开始听写          ← 只有这一环
  · 落点旁注（Q41）—— 一句后果，非方案卡
        跟光标：字进正在点的地方 + 去按键设应用
        进 {name}：字进 {name} + 去按键改目标
  · 高级（折叠 · Q44）
        口令唤醒（opt-in；关则只用麦/侧键）
        （仅应用落点）错前台时自动打开 {name} [默认关]
  · **Q30**：不放「情景优先 / 听写中只认收尾」只读提示
```

### 4.3 听写面 · 02 说完了（Q42）

```text
[02] 说完了字要怎样？
  · 三选一 outcome：发出去 | 先留着 | 不要了
  · 因果条随 outcome 变（例：停一会儿 → 字留下 → 不发）
  · 当前 outcome 的口令 hero（点大字改）
  · 「发出去」额外：
        应用落点：可选「在 {name} 里自动发」+ 延迟芯片
        跟光标：自动发禁用；提示「跟光标不能自动发」+ 链按键设应用
```

（旧 02 收尾 / 03 发送三卡结构并入本步；本方案不保留三步轨。）

### 4.4 SoftPad 桥面

- 范围条：当前应用 pill ·「换应用」→ 按键/习惯改目标（不本地 toggle）  
- 空态三态（Q43）：  
  - **未准备**：去 Soft Pad 准备键盘  
  - **有键盘·无口令**：加一句口令（写回）/ 去 Soft Pad 配置  
  - **有口令**：左键盘预览选键 · 右改说法 + 试说；高级 = 本键口令可说开关  
- 只列出**已有口令**的键；加口令同步 Soft Pad（Q45）

### 4.5 按键桥面

- 范围条 +「去按键页 →」  
- 空态：可只用按键；加口令写回 / 去按键页绑键  
- 有口令：左分类列表（仅已有口令）· 右说法 + 试说；高级 = 本条可说；接受类 gated → 链按键页开闸  
- **不**在此编辑 `appTargetId` / 快捷键位

### 4.6 摄像头桥面

- 范围条 +「去摄像头页 →」  
- 安全条：手势不能单独发出去（发送须二次确认）  
- 空态 / 有口令：同按键桥模式（动作列表 · 说法 · 试说 · 可说开关）  
- 识别与标定仍在摄像头页

### 4.7 01 / 壳 禁止

- 默认因果含「切到目标应用」  
- SoftPad、摄像头作为听写因果步骤  
- Cursor 试说 / 本地试说主 CTA（在听写 01 内）  
- 粘性积分墙、执行记忆看板  
- 文案「无目标」；语音页本地「全局 \| 应用」toggle  
- **方案卡双铬**（「全局听写 \| 应用情景」竞选）  
- **打开应用**页级第二面 / 01 内次入口  
- 01 内「相关：按键 · 摄像头 · SoftPad」当主导航（已升格为 face）  
- 持久化「上次 voiceFace」  
- 桥面空态推常见应用/命令推荐墙  

### 4.8 弱提示分工（Q15）

| 载体 | 何时 | 文案方向 |
|------|------|----------|
| **状态行**（常驻 · Q25） | **听写面** ∧ 应用落点 ∧ 前台≠目标 ∧ 高级关 | 挂在 **face 下方、听写步轨上方**；`现在在 {fg} · 习惯绑的是 {target} · 先切过去再说`；**桥面不显示** |
| **Toast**（~3s） | 同上条件下用户**说了**听写入口词被拒 | 当前窗口不是「{目标}」。请先切换，或到听写「高级」里打开自动拉起。 |
| 跟光标 | — | 不用上述两套；只用落点旁注引导限定 |

## 9. 明确不做

- 大模型运行时意图路由

- **打开应用**语音第二面 / roster 专面  
- **方案卡双铬**（全局听写 \| 应用情景竞选）  
- 01 内「相关三链」当主导航  
- 语音页兼任 SoftPad / 摄像头**配置台**（桥面只改口令；键位/标定回通道页）  
- 强制改成应用落点才能听写  
- Cursor 试说回流听写 01
