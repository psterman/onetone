## 1. 页面一句话

**语音设置 = 配置「听写」这条输入法环；不是 Agent 总控台，也不是跨应用自动化中心。**

| 意图 | 用户在干嘛 | 谁负责 |
|------|------------|--------|
| 输入法操作 | 字进光标处 | **本页主职**（01→02→03） |
| 定位 / 控 Agent | 发送、继续、新会话 | SoftPad / 迷你栏（点 = 说） |
| 对电脑操作 | 开应用、切窗 | 习惯目标 + 按键；跨应用拉起仅高级 |

按键 vs 语音：**同一习惯动作的两种触发器**（按 vs 说）；语音独特主职只有 **听写**。

## 2. 运行时裁决

```text
情景可匹配命令  >  听写入口
听写中          →  只认收尾词
未听写 + 已 arm →  只认当前亮卡
前台优先        →  应用情景下已在目标应用则直接执行
跨应用拉起      →  高级选项，默认关（仅应用情景）
全局听写        →  字进当前光标；不做错前台拦截
```

| ID | 规则 |
|----|------|
| R1 | 不靠设置页「模式总开关」；靠语境 + 状态机 |
| R2 | 听写中 / arm 未听写：grammar **互斥** |
| R3 | **情景匹配优先**，再考虑纯听写唤醒 |
| R4 | 常用情景 = `activeSceneId`（与按键 / SoftPad 同一世界） |
| R5 | 粘性 = **只抗切换**；从不自动 `activateScene` |
| R6 | 记录有效执行供大总结；**不**自动提权口令 |
| R7 | 空 `appTargetId`（**全局听写**）：听写跟光标；Agent 口令仍按 R3（不因全局而关闭命令环） |

### 2.1 应用情景 · 错前台

| 用户说了 | 高级「允许拉起」 | 行为 |
|----------|------------------|------|
| 听写入口词 | **开** | 打开/聚焦目标 → **开始听写**；**不**自动发送 |
| 听写入口词 | **关**（默认） | **不执行**；状态行已提示；**仅此时** toast 一次 |
| 继续 / 发送 / 新会话 | 任意 | **不**进听写；「继续」最多 **只聚焦目标**，不自动执行 slot |
| 情景认不出 + 未 arm | — | 不执行 |

### 2.2 两套方案铬（Q17–Q18 · Q24）

数据分叉不变：当前习惯 **空** `appTargetId` ↔ **非空**。UI **禁止**再写「无目标」；升级为并列第一类方案。

**与 [HABIT_UNIFIED_CONTRACT](../HABIT_UNIFIED_CONTRACT.md) 对应（Q38）：**

| 语音方案卡 | 契约层 | 不是 |
|------------|--------|------|
| **全局听写** | **§A 默认习惯**（无 `appTargetId` 的 baseline mapping）上的听写落点策略：字进光标 | **不是** §B 全局底座；引擎/麦 baseline 仍在 dock「引擎策略」 |
| **应用情景 · {name}** | 有 `appTargetId` 的习惯（契约「应用场景」）上的听写落点 + 错前台闸 | 不是另起一套「语音方案」名词（契约禁止混用「方案」；此处「方案卡」= UI 铬，数据仍是 mapping） |

对外「通用设置」可合并称呼 §A+§B；语音页方案卡**只反射当前正在编辑习惯是否绑应用**，不编辑 §B。

| | **全局听写** | **应用情景** |
|--|--------------|--------------|
| 条件 | `appTargetId` 空 | 非空 |
| 名义 | 标题「全局听写」+ 徽章 | 「应用情景 · {name}」 |
| 承诺 | 字进当前光标；不做前台比对 | 前台优先；错前台可拦；高级可拉起 |
| 高级拉起 | **不出现** | 方案卡下折叠（Q22=A） |
| 错前台状态行 / toast | **不启用** | **两者都要**（Q15=A）：状态行常驻 + 说了才 toast |
| SoftPad「继续」等 | **仍有效**（R3 / Q18） | 同左；落点受目标约束 |
| 目标区形态 | 只读承诺 +「限定到某应用更稳 →」 | **只读旁注升级**：应用名只读 +「在按键页改 →」（§11 #6；非可编辑目标控件） |
| 侧链（Q23′） | **相关：按键 · 摄像头 · SoftPad** | 同上；「改目标」CTA ≠「相关·按键」（前者聚焦目标区，后者进按键通道） |
| 引导 | **不**为「未限定」弹 toast；**不**强制改成应用情景才能听写 | — |

切换归属：**仅按键/习惯**改 `appTargetId`；语音页**不**放「全局 \| 应用」本地 toggle（避免双写）。

对照稿：[voice-q24-scheme-chrome-compare.html](../../design-mock/voice-q24-scheme-chrome-compare.html)

## 3. 架构策略（壳与通道）

### 3.1 语音设置在壳中的位置

- 左栏仍只有 **「语音设置」** → `voiceWake`  
- **不**新增左栏「打开应用」或「全局语音」通道  
- 打开应用 = 语音抽屉内 **第二面**（独立 markup / `voiceFace=openApp`）  
- **Q19=A**：`openApp` 面时 **整轨隐藏** `#voiceFlowNodes` 与听写 01–03 卡；仅顶栏 + face 切换 + roster + dock  
- **Q20=B**：face 切换条 = **流程轨上方独立一行**（不进品牌顶栏）；两面始终对称可见；openApp 藏轨时切换条仍保留  
- **Q26**：左栏进语音设置 **默认听写面（A）**；侧链/深链可指定 `voiceFace=openApp`（C 能力）；**不**持久化「上次 face」   

### 3.2 与 SoftPad / 按键

| 能力 | 归属 |
|------|------|
| 听写口令 / 结束 / 发送词 | 语音 01–03 |
| 试麦克风（原本地试说） | 语音 **dock**，次要文字/ghost；**两面都显示**（Q13=B · Q21=A · Q28=A） |
| Cursor / Agent 试说 | SoftPad **Agent 面**（Q14=A）；听写「相关 · SoftPad」另落默认面（Q31=C） |
| 触发键、目标窗、全局↔应用切换 | 按键页；语音方案卡链按键时 **聚焦目标/情景编辑区**（Q32=B） |
| 打开应用声学口令 | 语音第二面；按键可投影/绑键 |

## 4. UI / 页面布局策略

### 4.1 壳层

```text
顶栏：语音听写 · 状态 pill · 保存到正在编辑的习惯
页级面切换（流程轨上方独立一行 · Q20=B · Q34=A）：听写 | 打开应用
反馈轨（Q25=A · Q27=B · Q15）：错前台**状态行** —— face 下方、流程轨上方；**仅听写面**；条件：应用情景 ∧ 不匹配 ∧ 高级关  
事件 toast（Q15）：同上条件且用户**说了**听写入口词被拒时弹出 ~3s（原型用「模拟被拒」按钮演示）
缺模型：setup banner
听写面：#voiceFlowNodes 01–03
打开应用面：roster（无三步轨 · Q19=A；无错前台状态行/toast；无方案卡 · Q29=A）
底栏 dock（两面同构 · Q28=A）：麦 · 引擎策略 · 【试麦克风】（次要文字/ghost · Q21=A）· 听到…
```

### 4.2 听写面 · 01 首屏

```text
[01] 怎么开启打字？
  · Hero：默认口令 + 别名 + 添加
  · 开启口令唤醒（opt-in）
  · 因果条：唤醒后 → 进入听写          ← 只有这一环
  · 方案卡（二选一 · Q24）—— §11 #6 只读旁注的升级铬，不是可编辑目标控件
        【全局听写】（= 契约 §A 默认习惯听写落点 · Q38；≠ §B 引擎底座）
          徽章「全局」· 字进当前光标
          主动作：限定到某应用更稳 →（按键 · 聚焦目标区 · Q32=B）
          相关：按键 · 摄像头 · SoftPad（Q23′ · §11 #5）
          （无高级拉起）
        【应用情景 · {name}】
          只读：目标应用 {name} · 在按键页改 →（聚焦目标区 · Q32=B）
          （折叠 · Q22=A）高级：允许拉起目标再听写 [默认关]
          相关：按键 · 摄像头 · SoftPad
  · **Q30=A**：不放「情景优先 / 听写中只认收尾」只读提示（规则只跑运行时）

[02][03] 现网收尾 / 发送三卡；本方案不重画结构
```

**Q23′（补 §11 #5）：**「相关」三链恢复 **按键 · 摄像头 · SoftPad**。应用情景下「在按键页改」仍是目标旁注动作（聚焦目标区）；「相关·按键」进按键通道首页/触发区——两链可并存，职责不同。  
**Q31=C：**听写「相关 · SoftPad」→ SoftPad **默认面**；勿与打开应用「试 Agent」深链混用。

### 4.3 打开应用面（语音内第二面）

- 入口：页级「打开应用」；**删除** 01 内 `打开应用 · 语音唤起 →`  
- 内容：roster + 录/测 + 添加 +「在按键页管理」  
- **空态（Q35=B）**：短说明（如「说出应用名来打开」）+ 主按钮「添加应用口令」；**无**常见应用推荐墙  
- **Q29=A**：**不**露全局/应用情景方案卡（方案卡仅听写 01）  
- 底部：侧链「去 SoftPad 试 Agent →」（**落 Agent 面** · Q14 · Q31=C；**空态也显示** · Q36=A）   
- **无**「在 Cursor 试说」主按钮；**无**「本地试说」（已迁 dock「试麦克风」，两面可见 · Q28=A）

### 4.4 01 禁止

- 默认因果含「切到目标应用」  
- 发送语义 / 自动发送  
- SoftPad、摄像头作为因果步骤  
- Cursor 试说主 CTA；本地试说主 CTA（在 01 内）  
- 粘性积分墙、执行记忆看板  
- 文案「无目标」；语音页本地「全局 \| 应用」toggle  
- 持久化「上次 voiceFace」（Q26：默认听写；仅深链可进打开应用）   

### 4.5 弱提示分工（Q15=A）

| 载体 | 何时 | 文案方向 |
|------|------|----------|
| **状态行**（常驻 · Q25=A · Q27=B） | **听写面** ∧ 应用情景 ∧ 前台≠目标 ∧ 高级关 | 挂在 **face 下方、流程轨上方**；`当前：{fg} · 目标：{target}`；**打开应用面不显示** |
| **Toast**（~3s） | 同上条件下用户**说了**听写入口词被拒 | 当前窗口不是「{目标}」。请先切换，或在高级中允许自动打开。 |
| 全局听写 | — | 不用上述两套；只用方案卡引导限定 |

- 语音页可编辑 `appTargetId` / 本地全局\|应用 toggle  
- 打开应用面重复完整方案卡 / 高级拉起（Q29）

## 10. 实现批次指针

详细文件级 plan 见审计文档 **§12**：

- **Batch A**：因果条、高级开关、打开应用第二面、拆 CTA、**方案卡（全局\|应用）**、相关链、反馈轨
