# 25秒第一人称叙事故事板
## 《深夜，谁在替我的声音找按钮？》

> 设计规范：参考主流 PPT 演示设计原则（一屏一意 / 文字分层 / 先画面后点题 / 快入慢出 / 统一安全区）

---

## 🎯 核心设计原则

| 原则 | 说明 |
|------|------|
| **一屏一意** | 每5秒场景只传达 1 个核心信息，只出现 1 句核心文案 |
| **先画面→后点题** | 画面先入建立情境（0-1s）→ 文字再出现解释（1-2.5s） |
| **文字三级分层** | 大标题(核心56px) / 副文字(说明18px) / 标注(细节+描边) |
| **快入慢出** | 文字 20 帧滑入(0.7s)，停留 3 秒(慢)，给足消化时间 |
| **统一安全区** | 文字固定在画面 上10%/下12% 区域，永不遮挡主体 |
| **第一人称贯穿** | 每句旁白都是"我"的内心独白，五句连成一个完整故事 |

## 🎨 文字动效统一规范

```
进入动画（快入）:
  opacity: 0 → 1   (20帧 / 0.7s, ease-out)
  translateY: 20px → 0

停留动画（慢出）:
  opacity 保持 1，轻微呼吸脉冲 (幅度0.02)

层级:
  大标题   56px / #fff / 字距3 / 投影
  副文字   18px / rgba(255,255,255,0.65)
  标注     brand-blue 描边 / 深底卡片
```

## ✅ 验收标准
1. 每个场景画面先动，文字后出现（≥0.5s间隔）
2. 文字永远可读（安全区 + 遮罩加深）
3. 五句第一人称旁白连读是一段完整故事
4. 节奏：快入慢出，不赶不拖
