1 实时语音卡 · 波形 + 打字光标

原版只有一行"实时识别"的死字串，看不出系统在不在工作。改成三件事：

顶部 监听中 状态 + 呼吸脉冲圆点，眼睛一瞄就知道系统在不在监听
中间 实时波形，20 根 bar 错峰跳动 —— 这才是"语音工具"该有的视觉信号
底部 识别文字 + 打字光标 ▎，光标 0.8s 闪一次，比静态文字"活"

2 识别引擎卡 · 三层信息

原版就一个 "本地离线识别" + 完整链路标签，信息全挤一行。拆成三层：

头部：引擎名 + 完整链路绿标（一眼看状态）
Meta 行：模型名 / 大小 / 延迟 —— 写等宽字体，像终端输出一样紧凑
语言切换：独立的 seg control，原版塞进文字描述里
三个动作按钮：资源目录 / 下载模型 / 重试启动 等宽并排，加 hover 状态

3 应用召唤卡 · 状态分层

原版 4 个应用挤在一行，"当前"按钮和其他"使用"按钮视觉差异弱。改成：

激活的 MiniMax 整行有 淡蓝背景，logo + 名称 + 快捷键全变 accent 色
当前 实心蓝按钮 vs 使用 描边白按钮，视觉权重差一档
每行的 快捷键 kbd 用真正的键盘样式（白底 + 底边阴影），和正文 monospace 分开
底部 虚线分隔 + 引导链接，去按键页管理快捷键

4 卡片层 · dashed 给引擎

三个卡片里只给"识别引擎"保留 dashed border —— 表达"这个还在跑/可能要重试"的不确定感。其他两个是确定性信息，给实线。

1 实时识别从死字串 → 波形 + 打字光标

原版只是把识别结果摆在那里，看不出系统在不在监听。改版加入波形动画和光标闪烁，"实时"二字真正兑现。

2 引擎卡片信息密度提升

原版只有 "本地离线识别" 一行字。改版加上 模型大小 · 延迟 · 完整链路状态，用等宽字体呈现 —— 像 dev tools 而不是用户文档。

3 应用快捷键 kbd 化

原版把 Ctrl + L 这种按键直接当文字显示，没有"键盘"的视觉重量。改版用真正的 kbd 样式（白底+下边框阴影），和正文 monospace 拉开。

4 当前/使用按钮视觉权重拉开

原版两个按钮都像二级操作。改版：当前 = 实心蓝，使用 = 描边白。再配合激活应用行的淡蓝底，整组视觉层级立刻清晰。

5 dashed border 只留给引擎卡

三个卡片里只有"识别引擎"保留 dashed border —— 暗示它"需要关注/可能需要重试"。其他两个确定性信息给实线，主次感就出来了。
