## 一、限免期的真实口径（先把三个事实摆正）

三行列表，不上表格（手机端会塌）：

- **不是「混元 3 被下架」** —— 是 11 月 4 日 Hy4 上线，Hy3、Hy4 限免同日到期。
- **不是「15 号彻底不免费」** —— 到期的是限时免费窗口；体验版仍在，免费额度用尽可消耗积分，订阅用户额度更高，每日免费资源有上限并提示重置时间，高峰可能排队。
- **199 不是唯一选项** —— 四档：体验版免费 / 标准版 99 / 高级版 199 / 旗舰版 999 元月付；连续包月 7 折（70 / 140 / 700），连续包年 5.6 折（672 / 1344 / 6720）。1,000 积分加量包 50 元（1 个月有效）。

补三条读者会感谢的：

- **限免期体验版就是全开** —— 官方表原文「Auto 模型调度（限免全模型可选）」「自动任务 3 个（限免 99 个）」。不花钱也能选全模型、开 99 个任务，瓶颈只剩 500 积分 + 5GB 资料库。
- **老用户保价** —— 7/1 前付费且已开月付自动续费的，2026-12-31 前仍按 58 元/月，2027-01-01 起才 70 元。
- **别拿 199 和 20 美元直比** —— 一个是积分制 + 本地文件操作 + 桌面执行，一个是纯订阅对话服务，权益包与计费口径都不同。

## 二、8 组对照：初级用法 → 建议用法（**原帖最强资产，必须救回来**）

> 改稿把原帖最有传播力的「初级 vs 建议」装置换成了能力章节罗列 —— 读者失去了「对号入座」的快感。**这一节是原帖赢改稿的地方，必须保留并扩写。**

| # | 初级用法（你大概在这样） | 建议用法（改完是这样） |
|---|---|---|
| 1 | 把它当高级搜索框，问两次看一眼就关掉 | 让它交付一个能打开、能交付、能被人挑毛病的成品；把验收标准写死（第四点缺了，它交的是"像报告的东西"） |
| 2 | 「帮我分析一下销售数据」 | 四段式：你有什么（事实）→ 你希望什么（判断标准）→ 你要什么（文风/长度/格式）→ **你要的结果**（验收标准） |
| 3 | 生成的内容保存到本地改 | 用资料库：MD 定内容、CSV 定数据、HTML 定表达，三者互相引用；AI 改 MD 不覆盖原文，以待确认呈现，接受才写入 |
| 4 | 「假设你是 xx，你能够 xx，帮我 xx」 | 用专家（单 Agent）/ 专家团（多 Agent 接力）；专家团积分通常是单专家的 3~5 倍，召唤前看余额 |
| 5 | 自己下载"微信开发者工具"开发小程序 | 说清四件事：谁用、干什么（多用动词）、哪些页面、要不要登录存数据、什么风格；扫码即可测，先验逻辑再谈资质 |
| 6 | 定制爬虫去抓数据 | 浏览器自动化 + Computer Use；**复用你已登录的会话**，不必交出账号密码；页数与频率写死（10 页以内），去重和字段规则提前定 |
| 7 | 打开公众号后台翻热点开写 | 从你 3-5 篇历史文章建人设 → 抓热点拆高赞结构 → 素材整合去 AI 味 → 一次给多标题并打分 → 定版式色板 → 生成封面/配图/信息图 → 转草稿箱 |
| 8 | 找各种软件、攒长提示词 | 把工作流封成 Skill（`SKILL.md` + 可选 scripts/references/assets）+ 定时任务；沉淀的是判断标准，不是文件 |

**第 8 行要加的实话**：官方只核到 `SKILL.md` 独立目录，三目录与分级加载属实践用法、不是官方承诺 —— 别当官方条款写。

**第 7 行要加的实话**：官方演示案例是复古 QQ 游戏街机厅、多轮改教学课件 PPT、3D 场景构建与网页开发；Blender/CAD 是专项训练，不是演示案例。

## 三、这半年它多了「眼睛」和「手」

- Hy4 首次引入**视觉理解**和**电脑操作（Computer Use）**：看懂截图、录屏、复杂图表，也能在图形界面和命令行里找按钮、点击、滚动、输入，根据页面变化接着做下一步。
- 对普通用户的意义不是「AI 会打游戏」，而是**你不用再把屏幕上的东西翻译成文字喂给它** —— 销售后台截图、竞品页面一屏、扫描件，直接丢。
- **Hy4 本身不直接出图出视频**，图像/视频任务会切到专用多模态模型按常规计费（Hy4 preview 期官方口径）。限免期想省额度，纯文本/代码/文档任务才吃 Hy4 限免。
- 连着的还有：文生图/图生图、文生视频/图生视频、3D 模型、图像去水印与抠图修复、长音频转写（含方言与说话人分离）、PDF 解析 —— 公众号那套封面/章节配图/信息图，不必再开第二个软件。

## 四、让它有记忆：资料库不是网盘，是上下文

- 打通的不止腾讯文档和 ima：**Buddy One**（官方名，不是 BuddyOneID）把 WorkBuddy、腾讯文档、腾讯会议、腾讯网盘、腾讯 ima 关联成一套账号，支持跨产品搜索。媒体口径：关联入口免费；Buddy One 有独立付费订阅。
- 产物去处四个：资料库、腾讯文档、ima 知识库、乐享知识库；可链接/微信/企业微信三种分享。
- **第三方连接器名单要收** —— 官方内置是 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘，并支持自定义 MCP；飞书/Discord/Gmail/GitHub/Notion/Jira/Slack 属自行配置或社区生态，写成「一键打通」会被打脸。
- 反直觉的好消息：**连接器自身读写不消耗积分**，只有 AI 对外部数据做理解、汇总时才计费。

## 五、三种班次：定时任务的「来源」比频率更重要

- 频率比原帖更宽：间隔、单次、每天、每周、每双周、每月、每年；同一任务的多个执行日期写在一条规则里。完成后可推企业微信，历次结果在「运行记录」。
- **三种来源**（决定你能不能放心出门）：

| 来源 | 在哪跑 | 能读本机文件吗 |
|---|---|---|
| 本地 | 本机客户端 | 能，但别关电脑、别退客户端 |
| 项目 | 对应项目内 | 按项目权限 |
| 云端 | 云端沙箱 | **不能** —— 提示词里别写本地路径；电脑关机也能跑 |

- 三个工作模式比很多提示词技巧值钱：**默认（Agent）**直接执行 / **Plan** 先出方案等确认 / **Ask** 只答不动手。官方那句判断法值得抄：「**如果『怎么做』比『做出来』更值得先讨论，就开 Plan。**」
- 移动端：App 可连自己的电脑接管任务，**Windows 与 macOS 桌面端都支持**；其中**屏幕接管**（实时桌面 + 虚拟键鼠）目前仅 Mac，Windows 即将上线。
- ⚠️ 定时任务**只按时间触发**；事件触发只见于项目外部数据源的 Webhook。执行体是模型/专家/技能/连接器。

## 六、三条能直接抄的实战链路

**① 小程序：先验证逻辑，再谈资质**
谁用、干什么（多用动词）、哪些页面、要不要登录存数据、界面风格。扫码即可测。需求文档可以一开始就写，也可以开发到一半让它反过来归纳存档。涉及登录、存储、云服务的部分有对应的托管后端能力，不必自己搭服务器。

**② 数据采集：复用登录态，但别写「绕过验证」**
准确合规的说法是：**你先在浏览器里登录好目标平台，AI 复用你已登录的会话，不必把账号密码交给它**。范围写死：只采你有权访问的数据、遵守站点协议、控制页数与频率（10 页以内）、去重与字段匹配规则提前写进指令。

**③ 公众号审稿台：先跑通，再开定时**
从历史文章提取 3-5 篇建账号人设 → 联网补热点、拆高赞结构与文风 → 素材整合 → 去 AI 味 → 一次给多个标题并打分 → 定版式与色板 → 按统一规范生成封面/章节配图/信息图 → 结构化建稿 → 转草稿箱。粗稿 1800-2200 字带摘要和金句；协作审校放腾讯文档，长期存档放资料库。
**务必保留的忠告**：第一次配置一次性完成各项授权，**先手动完整跑通一次、检查生成文件无误，再打开定时开关**；涉及对外发布先验链路。官方还有一句更朴素的：**让 AI 改你的文档、方案、表格之前，先把原文件复制一份备份。**

## 七、避坑清单（可直接抄走）

- [ ] **不要全盘授权** —— 工作空间别设成桌面或 C 盘根目录，按「项目/店铺/日期」建独立文件夹，处理更快也更精准。
- [ ] **涉及钱和法律的事不全自动** —— 最终售价、合规承诺、对外发布的重大文案，一定亲自过目。
- [ ] **定时任务必须先试跑** —— 主对话里手动完整跑一次再开定时；云端任务读不到本机文件，本地任务要求电脑在线。
- [ ] **流水线提示词必加异常兜底**：*「若遇到数据缺失或读取失败，请立即停止并通知我，切勿使用预估值编造数据继续往下跑！」*
- [ ] **Skill 与连接器只开当前要用的 2~3 个**，用完关掉；关闭 ≠ 卸载；优先装官方推荐的（非官方 Skill 可能存在提示词注入、越权访问、后门隐患）。
- [ ] **召唤专家团前看余额** —— 积分消耗通常是单专家的 3~5 倍。
- [ ] **改文件前先备份** —— AI 不是每次都稳定。
- [ ] **限免期别拿 Hy4 批量出图/出视频** —— 会自动切专用多模态模型并按常规计费。
- [ ] **修改一次只改一个地方** —— 说「把主标题字号改小一档、颜色换深蓝」，不说「改得高级一点」。
- [ ] **长需求末尾留余地**：*「请先给出第一版基础结构，待我确认后再细化修改。」*

## 八、所以，199 到底值不值？

**必须给结论。** 改稿的「给判断标准，不给结论」在知乎等于没落点。

建议结论（可被反驳，因而有传播力）：

> 值不值不取决于你用得多不多，**取决于你会不会配 Skills 和定时任务**。
> 不会配的人，订 999 也是闲置；会配的人，限免期的体验版（500 积分 + 5GB）够跑完验证。
> **所以顺序是反的**：先用限免窗口跑通一条完整链路，把判断标准沉淀下来，再决定要不要加钱。
> 如果你跑完发现瓶颈是「额度见底 / 自动任务不够 / 资料库塞满」，那是 99 元档（连续包月 70 元）的活；如果还要跨应用取数、云端定时跑、多人共享项目配置，再往上考虑 199，而且连续包年（5.6 折）比月付划算得多。
> 老用户别忘了：2026-12-31 前可能还在 58 元/月保价。

四组数字（体验版 500 积分 / Auto（限免全模型可选）/ 3 个（限免 99 个）/ 5GB ；高级版 9000 积分 / 全模型 / 30 个 / 20GB）—— **保留这张表**，它是全文最实用的一张。

收尾：

> 工具进化的方向，从来不是更会聊天，而是更会干活。而「值不值」这件事，只有你手上那份被它交付出来、并且真的被人用过的文件能回答。
> 以上。如果这份对照帮你少踩了一个坑，点个赞同 / 收藏；有我没核到的更新、或你跑通了的链路，欢迎评论区补，我会把可复现的收进下一版并标注出处。
